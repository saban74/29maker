# GD05 - 연회색 인프라형 (레퍼런스 B5 Increase, 형식만)

한 줄 아이디어: 장비 소재의 회색을 바탕으로 깔고, 굵은 검정 제목과 작은 라임 네모 하나로 "믿고 맡기는 기반 설비" 인상을 만든다.

## 빌린 것 (확인된 원리만)
- 연회색 바탕 + 굵은 검정 글자 + 아주 작은 면적의 선명한 강조색 1개
- 정보 위계: 제목, 한 줄, 링크 (제품군 6칸 전부 같은 순서)
- 꾸밈보다 정보 (아이콘, 그림자, 그라데이션 없음)

## 스스로 정한 것
- 라임은 버튼 뒤 네모, 맨 위 네모, "1981" 옆 네모에만 (면적 최소). 원본의 3D 로고 마크는 쓰지 않음
- 칸 구분은 선이 아니라 회색 단차와 검정 칸 교차
- 첫 화면은 제목 한 덩어리(8vw 이상)와 오른쪽 한 줄 설명. 사진은 전폭 크롭
- 사실 숫자: 1981, 45년, 매년 3~4회 세미나, 제품 사양(research 근거)

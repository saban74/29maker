# GD07 - 흰 종이 목차 (레퍼런스 B7 Harry Atkins, 형식만)

한 줄 아이디어: 제품소개를 카드 대신 카탈로그 목차처럼 한 줄씩 늘어놓고, 줄에 올리면 사진이 나타난다.

## 빌린 것 (확인된 원리만)
- 흑백의 성긴 화면, 큰 글자
- 프로젝트 목록(index) 형식 -> 제품 10줄 (번호, 제품군, 대표 모델, 시험 종류)
- 담담한 자기소개 -> 회사소개를 문장 하나와 연도 목록으로

## 스스로 정한 것
- 강조색 없음. 순수 흰색과 검정, 사진도 흑백 처리(grayscale)로 통일
- 번호는 실제 목록 번호라서 사용. 줄 사이는 연한 선, 위아래는 굵은 선 한 줄
- 사진은 흰 바탕 누끼(web/)만 사용, 오른쪽에 300px 고정 크기 미리보기(원본 270~660px 보다 키우지 않음). 휴대폰에서는 미리보기를 숨기고 글만
- 마지막은 "견적문의" 한 단어를 화면 폭으로 크게. 연혁은 company.md 사실만

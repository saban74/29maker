# SI/01 (C1 Q-Industrial 레퍼런스) 연회색 + 주황 카탈로그

한 줄 아이디어: 연회색 바탕에 강조색 하나, 거대한 "&"를 상징으로, 첫 질문을 "어떤 시험이 필요하세요?"로.

## 레퍼런스에서 빌린 것 (확인된 원리)
- 연회색 + 강조색 하나의 2색 체계(#E6E6E6 계열)
- 회사 글자 하나를 큰 상징으로 쓰는 것 (원본은 3D "Q" 렌더 -> 여기선 타이포 "&")
- 사이트 목적을 "제품을 쉽게 고르는 카탈로그"로 둔 것

## 스스로 정한 것 ([미확인] 부분)
- 강조색 주황 #E8500C (원본의 빨강, ESPEC 로고 빨강과 겹치지 않게 변경)
- 글꼴 Pretendard 900 단일, 사각 버튼, 시험 종류 탭(키보드 화살표 지원)
- 사진은 multiply로 회색 바탕에 녹임, 푸터에 큰 J&S
- 색: 회색 #E6E6E6, 짙은 회색 #D6D6D6, 먹색 #17181A, 주황 #E8500C, 흰색
- 사진: platinous-j-lineup, tsa-pair, hast-ehs-lineup, walk-in-tbe
- 확인 필요: 주소·전화, 사진 배경색이 회색과 안 맞으면 조정

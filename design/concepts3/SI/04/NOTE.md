# SI/04 (C4 Daylight 레퍼런스) 한 화면 한 문장

한 줄 아이디어: "1981년부터, 한국의 환경시험." 문장 하나로 첫 화면, 이후에도 화면마다 문장 하나.

## 레퍼런스에서 빌린 것 (확인된 원리)
- Big Type + Minimal: 큰 글자와 넉넉한 여백만으로 구성
- (원본 주소 미확인이라 참고 비중 낮음)

## 스스로 정한 것 ([미확인] 부분)
- 낮(연한 하늘색 회색) -> 밤(짙은 남색) 으로 끝나는 화면 흐름, 마지막만 어두운 워크인 사진
- 색: 낮 #EAF0F4 / #DBE5EC, 먹색 #0C1A27, 밤 #0B1622, 해 #FFB21A(버튼 전용)
- 움직임: 첫 문장이 세 토막으로 한 번 올라옴(움직임 줄이기 설정 시 정지)
- 글꼴 Pretendard 800 단일, 사진 tsa-pair, walk-in-tbe-dark
- 확인 필요: 주소·전화

# AW/01 해 질 녘 슬레이트 (레퍼런스 A1 Seasats)

**한 줄:** 흰 테두리 안에 둥근 큰 사진 패널, 오른쪽에 장비 색에서 뽑은 단색 메뉴 블록 기둥, 주장 목록이 한 줄씩 밝아지는 고정 장면, 푸터만 번트 오렌지로 온도 반전.

## 레퍼런스에서 빌린 것
- 10px 흰 테두리 + 둥근 사진 패널 84% / 메뉴 기둥 14%, 선·아이콘 없이 색 블록으로 메뉴 구분
- 장비 한 대를 고정하고 주장 6줄을 흐리게 다 보여 준 뒤 스크롤 따라 한 줄씩 밝힘, 작은 사각 인셋 사진 + 모노 태그
- 푸터만 반대 온도(오렌지)로 뒤집기, 푸터 맨 아래 가득 찬 워드마크, 스크롤 거리 읽기값(cm)
- 가벼운 세리프 큰 제목 + 16px 본문

## 스스로 정한 것
- 블록 색은 Platinous·TSA 사진의 회색/남청/흑연에서 뽑음(블러시·세이지·슬레이트·딥블루·흑연)
- 사진 filter로 어둡게(흰 글자 대비 확보), 제품 카드 3장, 주장 문구와 태그 수치는 research 사양만(AR -70~+180°C, 10~98%rh, TSA +200/-70, EHS-412 +162.2°C/0.392MPa, 워크인 -40~+80°C, ECO 최대 70%)
- 글꼴: Noto Serif KR(Google, 가벼운 세리프) + Pretendard

## 확인 필요
- 주소·전화·이메일. 습도 줄의 "Platinous J 20~98%rh" 태그는 research 근거.
- "사십오 년째 같은 온도를 지킵니다"는 문구 시안(실적 주장 아님).
- 첫 화면 사진은 어둡게 처리한 카탈로그 사진: 원본 색을 원하면 filter 제거 필요.

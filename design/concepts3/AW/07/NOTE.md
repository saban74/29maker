# AW/07 LPAS 시안 (A7)

**한 줄 아이디어:** 산업(반도체·전기전자·배터리·자동차·소재)마다 같은 명도의 흙빛 바탕색 하나씩을 주고, 어둡게 낮춘 장비 사진 위에서 첫 카드가 오른쪽 끝에 살짝 보이는 가로 레일로 다음 화면을 이끈다.

## 레퍼런스에서 빌린 것
- 첫 화면: 밝기 50%로 낮춘 전체 화면 사진, 왼쪽 위 얇은 워드마크, 오른쪽 위 어두운 메뉴 알약, 왼쪽 아래 75px 제목, 오른쪽 끝에 200px만 보이는 첫 산업 카드.
- 산업 카드: 위 약 68% 사진(8:5) + 아래 단색 패널(산업명, 두 줄 설명, 원형 + 표시). 가로 스크롤 스냅 레일. 카드 호버는 같은 색의 밝은 틴트.
- 색 체계: 흰 바탕 + 숯색(#262626) + 산업별 저채도 바탕 5개(토프 #cfc6bd, 점토 #dcc4b3, 세이지 #c1cfc4, 안개 청회 #c5d1dc, 모래 #d8d2bd). 그 외 강조색 없음.
- 글자: 한 글꼴(Pretendard) 400 굵기 중심, 문장형 대소문자, 짧은 크기 단계(75 / 56 / 38 / 16 / 14). 50px 바깥 여백.
- 로고 모양을 사진 모서리 한 곳에만 쓰는 45도 컷(첫 카드 왼쪽 위, 모자이크 첫 사진 왼쪽 위, 마지막 사진 오른쪽 아래로 묶음을 감쌈).
- 8:5 사진 모자이크(큰 것-작은 것-작은 것 / 작은 것-작은 것-큰 것, 작은 사진은 큰 사진 아래선에 맞춤), 사진은 clip-path 로 와이프 등장. 어두운 사진 위 산업 이름 목록(호버 때 산업 색), 숯색 푸터.

## 스스로 정한 것
- 영상 대신 정지 사진 + 40초 느린 확대(순수 CSS). 영상이 생기면 `.hero-bg`만 교체.
- 제목은 레퍼런스의 3줄 대신 규칙에 맞춰 2줄. 로더(4.5초)는 넣지 않음.
- 산업 5개: PLAN.md 6개 중 항공우주·방산을 빼고 소재·기타만 남김(쓸 수 있는 장비 사진이 없어서). 산업별 설명은 PLAN.md와 제품 자료에 있는 용도만 사용.
- 45도 컷은 J&S 로고 모양이 정해지기 전 임시 모티프(로고 확인 필요).
- 카드 이동은 CSS 스냅 + 이전/다음 버튼. 레퍼런스의 화면 고정(pin) 스크롤은 쓰지 않음.
- 소식 4건은 research/espec/news.md 실제 항목(날짜 그대로). 링크는 `#`.

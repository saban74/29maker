# AW/02 시험 관제 (레퍼런스 A2 USAvionix)

**한 줄:** 검은 화면에 고정된 장면 하나가 네 장(워크인, 열충격, HAST, Platinous J)으로 바뀌고, 글은 화면 귀퉁이에서 투명도로만 바뀌며, 장비 위에 1px 상자와 측정값이 붙는다.

## 레퍼런스에서 빌린 것
- 검정 바탕 + 흰 글자, 제목 왼쪽 위(자간 -0.04em, 600), 설명 왼쪽 아래, 측정값 오른쪽 아래, 장 번호 아래 가운데. 가운데는 장비에 양보
- 색에 일 하나씩: 하늘색 = 저온 값, 호박색 = 고온 값, 산호색 = 압력 값만. 메뉴·버튼에는 쓰지 않음, 글자의 5% 미만
- 장비 위 1px 경계 상자 + 이름표, 열충격 장에는 점선 이동선
- 장면 하나를 장별로 스크롤(약 140vh씩), 글은 opacity 전환만(나갈 때 .25s, 들어올 때 .4s 지연 .2s)
- 이야기 뒤 밝은 사진 카드 3장(하나 넓게, 둘 좁게, 호버·포커스로 열림)
- Geist + 11~12px 모노 대신 문장형 14~15px 숫자(tabular-nums) (스킬의 "house version")

## 스스로 정한 것
- 회색 스튜디오 사진은 어둡게 + 가장자리를 검정으로 녹이는 마스크로 "어둠 속 장비"처럼 처리
- 측정값은 research 사양만(EBE -40~+80°C 10~95%rh, TSA-73ES, EHS-412, Platinous J 120~800L -70~+100°C 20~98%rh). 상자 위치는 사진 위 대략 위치(수동 지정, 시안 수준)
- 상자 이름표 중 "고온조/저온조 +200/-65°C"는 사진 속 화면 표시값. 상단/하단 시험조 등은 눈으로 본 구분

## 확인 필요
- 주소·전화·이메일, 상자 위치는 실제 제작 시 다듬을 것. JS가 꺼지면 1장만 보임.

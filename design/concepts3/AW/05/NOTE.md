# AW/05 The Watch 시안 (A5)

**한 줄 아이디어:** 회색 스튜디오 바탕에 Platinous J 한 대가 서고, 뒤에 깔린 초대형 제품명 "PLATINOUS"의 가운데 글자를 장비가 가린다.

## 레퍼런스에서 빌린 것
- 첫 화면: 장비 사진 한 장 + 화면 폭 12%급 초대형 글자, 장비가 가운데를 가림(같은 사진을 장비 모양으로만 잘라 글자 위에 겹침). 본문·버튼 없이 작은 안내 두 줄만.
- 완전 무채색(#e8e8e8 → #0a0a0a). 따뜻한 색은 황동 한 색(밑줄)에만.
- 큰 글자와 15px 작은 글자만 쓰고 중간 크기 없음. 한 줄 안에서 회색·검정·흰색 네 단계로 깊이를 냄(-70°C / +200°C / 98%rh / 45년).
- 장비가 큰 글자 위에 떠서 글자 일부를 가리는 배치, 좁은 설명 기둥(230px).
- 마지막 "분해도": 사양표 대신 장비 부분 사진 4장을 가로 한 줄 표본처럼 놓고 세로 작은 라벨.
- 바탕이 밝은 회색에서 검정으로 넘어감.

## 스스로 정한 것
- 제품명은 Platinous J로 하고 화면 폭에 맞춰 Michroma(넓고 각진 Google 글꼴 1종)로 설정. 한글은 Pretendard 800.
- 뒤 레퍼런스의 3D 회전과 38화면 타임라인은 쓰지 않음(순수 CSS). 움직임은 첫 화면 한 번(사진 천천히 안착, 제품명 떠오름).
- 장비 사진을 바탕과 섞기 위해 multiply + 가장자리 마스크 사용.
- 본문 최소 15px(레퍼런스의 12px는 읽기 어려워 올림). 제목은 레퍼런스처럼 극단적으로 큼.
- 푸터: "J&S"를 SVG textLength로 양 끝까지.

## 확인 필요
- 전화, 이메일, 주소 [확인 필요]. 워크인 수치(4.2~52.7m³, -40~+80°C)는 research 자료 그대로, 모델별 차이는 확인 필요.
- "PLATINOUS"가 장비 뒤로 가려지는 위치는 사진 비율에 맞춘 비율값이라, 사진을 바꾸면 `.cut`의 clip-path를 다시 맞춰야 함.
- 브라우저로 열어 보지는 못함(이 환경에서 렌더링 확인 불가). 제품명 폭(12cqw)이 Michroma 실제 폭과 어긋나면 값을 조정.

# AW/03 온도 게이지 (레퍼런스 A3 United Carriers)

**한 줄:** 거의 검은 첫 화면에 점으로 그린 큰 온도 게이지(위 주황 = 고온, 아래 파랑 = 저온), 메뉴는 제목과 같은 선에 서는 세로 링크, 흰 구역은 왼쪽 문장 + 오른쪽 거대한 숫자 기둥, 누끼 장비가 흰 구역 아래 끝에 서고 검은 띠가 땅이 된다.

## 레퍼런스에서 빌린 것
- 왼쪽 29% 위치에 세로 메뉴 + 제목 + 본문이 한 기둥(가로 메뉴 없음), 왼쪽 바깥에는 작은 정사각 썸네일
- 화면 높이 90% 점(dot-matrix) 원형 그래픽 + 테두리에만 주황·파랑. 색은 "물체"에만(게이지 테두리, 핀, 장비), #060503 / #fff / #f26a1b / 전기 파랑
- 각진 테크노 대문자 숫자(Chakra Petch) 큰 통계 + Pretendard 본문
- 강조를 굵기 대신 앞 두 줄 회색 / 뒤 두 줄 검정으로
- 흰 2단: 왼쪽 문장, 오른쪽 선으로 나뉜 큰 숫자
- 흰 배경 누끼 장비를 구역 아래 끝에 세우고 다음 검은 띠가 땅
- 푸터에서 가로로 흐르는 옅은 회색 한 줄(업종 이름 대신 제품 라인 이름)

## 스스로 정한 것
- 지구본 대신 "-70~+180°C 온도 게이지"(원 안 점, 핀 4개에 research 사양: TSA +200, AR +180/-70, 워크인 -40)
- 숫자 4개는 근거 있는 값만(1981, 45년, 연 3~4회 세미나, AR -70~+180°C)
- 제품 목록 5줄(작은 회색 분류 + 굵은 이름), 누끼 3장은 원본보다 키우지 않게 폭 제한

## 확인 필요
- 주소·전화·이메일. 누끼 PNG 실제 폭은 270~660px 범위(브리프)라 크게 쓰지 않음.
- 통계 구분선은 레퍼런스대로 가는 선(스킬 금지 규칙보다 레퍼런스 우선).

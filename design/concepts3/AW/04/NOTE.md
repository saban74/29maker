# AW/04 측량 도면 (레퍼런스 A4 CoMinVi)

**한 줄:** 남색 어둠 속 장비 사진에 모노 주석이 핀으로 꽂힌 첫 화면, 구역마다 70% 폭 큰 문장이 스크롤에 따라 글자 단위로 회색에서 검정으로 물들고, 흰색과 옅은 세이지가 번갈아 흐르며, 마지막은 눈금 링 안에 장비가 서는 제품 라인.

## 레퍼런스에서 빌린 것
- 남색 히어로 + 왼쪽 정렬 굵은 흰 2줄 제목, 장비 위 핀(점+선)에 2줄 모노 주석
- 오른쪽 아래 바로가기 카드 2장(흰 라벨 띠 + 검은 삼각형)
- 흰색 ↔ 옅은 세이지(#ebf0ed) 구역 교대, 구역마다 70% 폭 문장 앞에 2줄 모노 태그(코드 위, 구역명 검은 라벨)
- 사진(48) + 숫자 격자(52): 2열×3행, 위쪽 가는 선, 작은 선 아이콘, 36px 굵은 숫자 + 12px 모노 캡션
- 3열 정사각 흰 카드(8px 간격, 위 아이콘·아래 이름), 가운데는 비움
- 눈금 링 안에 누끼 장비 + 왼쪽 세로 제품 목록(선택은 검정, 나머지 옅은 회색) + 링 가장자리 사양 태그
- 글자 단위 회색 → 검정 스크롤 물들임(Lenis 없이 일반 스크롤)

## 스스로 정한 것
- 첫 화면 사진은 어두운 워크인 챔버 사진을 `mix-blend-mode: screen`으로 남색 위에 녹임(CG 광산 장면 대신)
- 주석 문구, 숫자 6개는 research 사양만(1981, 45년, 연 3~4회, AR -70~+180°C, Platinous J 20~98%rh, TSA +200°C). "TABAI와 1981년 총판 계약", "2015 위탁 시험소 개설"은 company.md 연혁
- 눈금 링 채움은 conic mask(제품 수/5)로, 선택하면 눈금이 한 칸 더 차오름. 글꼴: Pretendard 800 + 시스템 모노(12px, 데이터 표기만)

## 확인 필요
- 위탁 시험 이용 조건, 주소·전화·이메일. 주석 핀 위치는 사진 위 대략 위치.
- 누끼 PNG는 폭이 작아(270~660px) 링 안 52%로 제한함.
- 첫 화면 사진은 AW/02와 같은 원본(어두운 워크인)이나 처리와 구성이 다름.

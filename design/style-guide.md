# J&S ENGINEERING 디자인 규칙 (style-guide)

모든 시안은 `design/common.css` 하나를 함께 씁니다. 색과 크기는 파일 맨 위 `:root`에 모여 있어, 거기만 고치면 전체가 바뀝니다.
기준: 사용자가 준 참고 시안(`design/reference/`)의 스타일. 단, ESPEC 본사 사이트처럼 보이지 않게 제이에스 엔지니어링 고유의 문구와 구성을 씁니다.

## 1. 분위기
- 흰색, 연회색, 검정에 가까운 짙은 남색만 쓰는 절제된 단색 톤. 강조색은 거의 쓰지 않습니다.
- 얇은 선(1px), 넉넉한 여백, 큰 사진, 자간 넓은 영문 대문자 문구. 장식(온도계 그림 등)은 쓰지 않습니다.
- 어두운 구역은 첫 화면(선택), 숫자 강조 구역, 하단 견적 띠, 푸터에만 씁니다.

| 이름 | 코드 | 쓰는 곳 |

| navy (짙은 남색) | `#101D33` | 메인 숫자 구역 |
| text | `#1A2230` | 본문 |
| muted | `#5E6877` | 보조 글자 |
| faint | `#8B94A1` | 영문 작은 라벨, 출처 문구 |
| line | `#E2E5EA` | 얇은 선, 카드 테두리 |
| soft / softer | `#F3F4F6` / `#F8F9FA` | 연회색 배경 |
| accent (강조, 최소 사용) | `#2B5C9E` | NEW 표시, 제품 상세 핵심 수치, 키보드 포커스 |

## 3. 글꼴과 글자 크기
- 한글·본문: Pretendard (없으면 Noto Sans KR, Apple SD Gothic Neo, 맑은 고딕). 영문 로고·라벨·숫자: Inter (없으면 Pretendard). 외부 링크 없이 시스템에 있는 글꼴을 씁니다. 제작 단계에서 Pretendard 파일을 `site/`에 넣어 쓰는 것을 권합니다.
- 본문 16px / 줄 간격 1.7. 휴대폰 15px.
- 제목: h1 44px(휴대폰 30), h2 34px(26), h3 20px(18). 모두 굵게(700), 자간 -0.02em.
- 영문 대문자 라벨(eyebrow): 12px, 자간 0.24em, 연한 회색. 큰 한글 제목 바로 위에 둡니다 (예: SOLUTION → 산업별 신뢰성 솔루션).
- 첫 화면 영문 큰 문구: 64px(휴대폰 34), 가는 글자(300), 자간 0.08em, 대문자.
- 로고: "J&S ENGINEERING" 22px 굵게(800) + 아래 "TOTAL TEST SOLUTION" 8px, 자간 0.32em.

## 4. 버튼
| 종류 | 클래스 | 모양 |
|---|---|---|
| 주 버튼 (견적문의) | `.btn` | 검정 남색 바탕, 흰 글자, 모서리 4px, 높이 48px (작게 `.btn--sm` 38px) |
| 보조 버튼 | `.btn--outline` | 흰 바탕, 회색 테두리, 마우스를 올리면 검정으로 |
| 어두운 바탕 위 버튼 | `.btn--light` | 흰 바탕, 검정 글자 |
| 글자 링크형 ("회사소개 보기 →") | `.link-arrow` | 글자 + 얇은 밑줄 + 화살표. 마우스를 올리면 화살표가 살짝 이동 |
- 한 화면에 검정 주 버튼은 하나만 눈에 띄게 둡니다.

## 5. 여백과 칸
- 8px 단위: 8 / 16 / 24 / 32 / 48 / 72 / 112. 섹션 위아래 112px (휴대폰 64px).
- 내용 폭 최대 1240px, 좌우 여백 40px (휴대폰 20px).
- 상단 메뉴 높이 72px(휴대폰 60px), 흰 배경 + 아래 얇은 선, 스크롤하면 위에 고정.
- 카드: 1px 선, 모서리 4px, 그림자 거의 없음. 마우스를 올리면 선이 검정으로.

## 6. 화면 구성 부품 (클래스)
| 부품 | 클래스 | 설명 |
|---|---|---|
| 상단 메뉴 + 펼침 메뉴 | `.site-header` `.nav` `.sub` | 왼쪽 로고, 가운데 메뉴 6개, 오른쪽 검색·KR·견적문의. 펼침은 가로 전체 폭 |
| 첫 화면 | `.hero` + `.quick` | 큰 사진 + 영문 문구 + 한글 부제 + 4개 바로가기(01~04) |
| 산업별 카드 | `.ind-grid` `.ind-card` | 사진 위에 이름, 가로 6개(태블릿 3, 휴대폰 2) |
| 제품 카드 | `.prod-grid` `.prod-card` | 흰 배경 장비 사진 / 제품명 / 종류 / 온도 범위 |
| 숫자 강조 줄 | `.stats` `.stat` | 큰 가는 숫자 4칸 (근거 있는 숫자만, 없으면 [확인 필요]) |
| 안쪽 페이지 머리 | `.page-head` `.page-hero` | 작은 영문 라벨 + 큰 한글 제목 |
| 탭, 필터 | `.tabs` `.filters` | 제품 상세 탭 줄은 스크롤 시 고정 |
| 하단 견적 띠 | `.cta-band` | 연회색(밝은 쪽) 또는 `--dark`(검정) |

## 7. 사진 자리표시 (`.ph`)
- 실제 사진이 없으므로 회색 그라데이션 상자 안에 어떤 사진이 들어갈지 글자로 적습니다. 예: "본사 건물 외관 사진 들어갈 자리", "반도체 웨이퍼 사진", "제품 사진 들어갈 자리 (흰 배경)".
- 종류: 밝은 회색(기본), `.ph--dark` / `.ph--mid`(산업 사진 분위기), `.ph--product`(흰 배경 장비 사진), `.ph--hero`(첫 화면 전체).
- 외부 사진 링크는 쓰지 않습니다. ESPEC 로고가 크게 보이는 장비 사진은 첫 화면에 쓰지 않습니다.

## 8. 휴대폰 화면 기준
- 720px 이하: 메뉴는 햄버거(☰) + "견적문의" 버튼만 남깁니다. 검색·KR은 숨김.
- 첫 화면 바로가기는 2열, 산업 카드 2열, 제품 카드 2열, 숫자 2열. 표는 옆으로 밀어 보기.
- 1024px 이하(태블릿): 산업 카드 3열, 제품 카드 2열, 상세 페이지는 사진 위 / 정보 아래.
- 터치 버튼 높이 최소 38px. 움직임 줄이기 설정(prefers-reduced-motion)을 지킵니다.

## 9. 문구 규칙
- 사이트 어디서나 "ESPEC 한국 단독 총대리점"이 보이게 (메뉴 옆 배지, 첫 화면 작은 표시, 푸터, 제품 상세 경로줄).
- 근거 없는 숫자는 쓰지 않고 `[확인 필요]`로 둡니다. 참고 시안의 20+ / 500+ / 100+ / 24/7과 베트남·미국·유럽 거점은 쓰지 않습니다.
- 사양표 아래에는 항상 "ESPEC 공개 자료(수집일 2026-10-29) 기준 ..." 출처 문구를 둡니다.

## 10. 파일 구성
`main.html`(메인) / `about.html` / `network.html` / `products/index.html` / `products/platinous-j.html`, `tcc-series.html`, `semiconductor-evaluation.html` / `product-template.html`(제품 상세 공통 틀) / `solutions/index.html`, `solutions/semiconductor.html` / `resources.html` / `service.html` / `news.html` / `contact.html`
- 메인 변형(어두운 첫 화면)이 필요하면 `.hero--dark` 와 `.ph--hero.ph--dark` 를 붙이면 됩니다.
- `design/pages/*.html`, `design/products/walk-in.html` 은 옛 시안의 빈 안내 파일입니다. 삭제해도 됩니다.

# 제이에스 엔지니어링 디자인 규칙 (style-guide)

모든 시안은 `design/common.css` 하나를 함께 씁니다. 색과 크기는 파일 맨 위 `:root`에 모여 있어, 거기만 고치면 전체가 바뀝니다.

## 1. 분위기
- 흰 바탕, 짙은 네이비 글자, 청록 강조색 한 가지. 차분하고 정확한 기업 느낌.
- 고유 모양: 온도계 눈금을 닮은 선(`.ticks`, 로고 안 눈금). ESPEC 로고·색·배치는 따라 하지 않았습니다.
- 어두운(네이비) 구역은 "왜 제이에스 엔지니어링인가"와 꼬리말에만 씁니다.
- 로고는 자리표시입니다. 회사 로고 파일을 받으면 `.brand__mark`를 바꿉니다 `[확인 필요]`.

## 2. 색상
| 이름 | 코드 | 쓰는 곳 |
|---|---|---|
| 네이비 700 | `#0E2A47` | 제목, 로고, 표 머리 |
| 네이비 900 | `#0A1A33` | 어두운 구역, 꼬리말 |
| 청록 600 (강조) | `#0A7C86` | 견적 버튼, 링크, 강조 줄 (흰 글자 대비 약 5:1) |
| 청록 700 | `#08646C` | 버튼 위에 마우스 올렸을 때 |
| 청록 50 | `#E8F5F6` | 연한 강조 배경 |
| 본문 글자 | `#1B2430` | 본문 |
| 보조 글자 | `#5F6B7C` | 날짜, 설명 (흰 바탕 대비 4.5:1 이상) |
| 연한 회색 | `#F5F7FA` / `#EBEEF3` / `#CBD2DC` | 번갈아 쓰는 배경 / 구분선 / 테두리 |
| 확인 필요 표시 | 배경 `#FFF1C2`, 글자 `#6B4200` | `[확인 필요]` 자리표시 (눈에 띄게) |
| 수상 표시 | 배경 `#FFF4D6`, 글자 `#6B4E00` | 굿디자인상 등 |

경고색(빨강)은 필수 표시(`필수`)에만 씁니다.

## 3. 글꼴과 글자 크기
- 글꼴: Pretendard (무료, SIL OFL) -> Noto Sans KR -> 시스템 글꼴 순서. 인터넷 연결이 없으면 시스템 글꼴로 보입니다.
- 굵기는 400(본문), 700(제목·버튼), 800(큰 제목)만 씁니다.

| 용도 | 휴대폰 | 큰 화면(768px~) |
|---|---|---|
| 첫 화면 큰 제목 | 32px | 44px |
| 쪽 제목 h1 | 28px | 36px |
| 구역 제목 h2 | 24px | 28px |
| 소제목 h3 | 18px | 20px |
| 본문 | 16px | 16px |
| 작은 글씨(표, 설명) | 14px | 14px |
| 아주 작은 글씨(출처) | 13px | 13px |

본문 줄 간격 1.7, 한글 단어가 중간에 끊기지 않게 `word-break: keep-all`.

## 4. 여백 (4px 단위)
4 / 8 / 12 / 16 / 24 / 32 / 48 / 72px. 구역 위아래는 휴대폰 48px, 큰 화면 72px. 내용 폭은 최대 1160px, 좌우 16px(휴대폰) / 24px.

## 5. 버튼 (모양: 모서리 6px, 높이 48px 이상)
| 종류 | 클래스 | 언제 쓰나 |
|---|---|---|
| 주 버튼 (청록 채움) | `btn btn--primary` | 견적 문의, 이 장비 견적 받기. 화면마다 가장 눈에 띄게 1개 |
| 보조 버튼 (네이비 테두리) | `btn btn--secondary` | 카탈로그 보기, 장비 찾기 |
| 약한 버튼 (청록 테두리) | `btn btn--ghost` | 자세히, 문의, 이 모델 견적 |
| 밝은 버튼 | `btn btn--light` | 어두운 구역 위 |
| 작은 버튼 | `btn--sm` | 표, 카드 안 (높이 40px) |

버튼 문구는 "문의하기" 한 가지로 통일하지 않고 상황에 맞게 구체적으로 씁니다. 휴대폰에서는 버튼이 한 줄을 꽉 채웁니다.

## 6. 자주 쓰는 부품
- 카드 `.card` (모서리 8px, 연한 그림자), 링크 카드 `.card--link`, 특징 카드 `.card--feature`(위쪽 청록 줄)
- 표시 `.chip--new`(NEW), `.chip--award`(수상), `.tag`(산업 태그)
- 핵심 수치 3개 `.kpi`, 사양표 `.table-wrap` + `table.spec`(휴대폰에서 옆으로 밀기)
- 지원 흐름 5단계 `.flow`, 연혁 `.timeline`, 단계 표시 `.stepper`, 폼 `.field`
- 하단 견적 띠 `.cta-band` (모든 주요 페이지 맨 아래)
- 출처 문구 `.source-note` (사양표 아래에 반드시)

## 7. 사진 자리
- 회색 점선 상자 `.ph`에 "제품 사진 들어갈 자리"를 적습니다. 비율 `ph--16x9`, `ph--4x3`, `ph--sq`.
- 스톡 사진·가짜 사진은 쓰지 않습니다. 사진이 없으면 "사진 준비 중"으로 둡니다.

## 8. 휴대폰 기준
- 기준 화면 폭 360px. 가로 스크롤이 생기지 않아야 합니다(표만 예외).
- 960px 미만: 머리말에는 로고 + 견적 문의 버튼 + 메뉴 버튼만 보입니다. 메뉴는 CSS만으로 열고 닫습니다(자바스크립트 없음). 전화 걸기는 메뉴 맨 아래.
- 640px 미만: 2열 카드는 1열로, 큰 화면에서만 4열.
- 터치 대상(버튼, 입력칸, 선택칸)은 높이 44~48px 이상.
- 움직임은 `.rise`(나타나기)와 카드 올라오기뿐이며 `prefers-reduced-motion`을 지원합니다.

## 9. 사이트 전체 규칙
- 모든 페이지 머리말에 "ESPEC 한국 단독 총대리점" 배지, 꼬리말에 상표·출처 문구.
- 자료에 없는 정보는 `<span class="tbd">[확인 필요]</span>`로 표시합니다. 숫자를 지어내지 않습니다.
- 사양 수치는 `research/espec/products/*.md` 값 그대로, 표 아래에 출처 문구와 원문 링크.
- 회전 슬라이드, 자동 팝업, 채팅 팝업, 자동재생 영상은 쓰지 않습니다.

## 10. 파일 구조
```
design/
  common.css  style-guide.md  main.html  product-template.html
  pages/    about, products, applications, resources, news, contact
  products/ platinous-j, semiconductor-evaluation, walk-in
```
- 시안끼리의 링크는 파일 경로로 연결됩니다. 아직 시안이 없는 제품 상세 링크는 `product-template.html`로 임시 연결했습니다.
- 인터넷에서 불러오는 것은 글꼴(jsDelivr) 하나뿐입니다.

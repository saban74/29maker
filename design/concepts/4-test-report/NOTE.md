# 4. test-report (시험 성적서)

**한 줄 아이디어:** 이 페이지에서 45년의 공급 기록이 신뢰성 시험 성적서 한 장(문서 번호, 사양표, 점검표, 서명과 도장)이 된다.

## 색 (6)
- 책상 #CDD4DC / 용지 #FFFFFF / 먹색 #14233A / 서식 파랑 #2C5A9C / 표 머리 #E8EEF6 / 도장 빨강 #C32B30

## 글꼴
Pretendard 한 가지. 제목은 800, 사양 숫자는 tabular-nums.

## 배치 개념
회색 책상 위에 A4 같은 용지 한 장. 제목 옆에 문서 정보표, 아래로 1~6 조항(번호는 문서의 조항 번호). 사양표(실제 표), 장비 사진 보관 칸, 체크박스 점검표, 서명 칸과 도장으로 끝남. 휴대폰에서는 표가 항목별 카드로 쌓임.

## 참고한 스킬 원칙
제목 두 줄 이내, 본문 16px 이상 진한 색, 키보드 포커스, 선과 번호는 문서 구조 자체라서 의도적으로 사용(브리프 4번 요구), 그라데이션 없음, 첫 화면에 h1.

## 확인 필요
- 문서 번호 `JS-RPT-[확인 필요]`는 장식용 자리표시, 실제 번호 체계 없음
- 연락처, 주소 [확인 필요]
- "연 1회 정기 방문"이 아니라 "매년"으로만 씀. 연혁은 판독된 항목만 사용
- 도장은 디자인 장치이며 실제 사용 도장이 아님
- 장비 사양은 ESPEC 공식 사이트 최대 범위. AMR 모델명 확인 필요
- 사진은 모두 원본 이하 크기로 표시

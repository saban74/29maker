# 3. temperature-axis (온도 축)

## 한 줄 아이디어
이 페이지에서 **장비의 사용 가능 온도 범위**가 **하나의 온도 눈금(-70 ~ +300°C) 위의 막대**가 되고, 방문자가 시험 온도와 습도를 고르면 눈금 위에 띠가 생겨 맞는 장비만 남는다.

## 조작 요소 (live thing)
- 가장 낮은 온도 / 가장 높은 온도 슬라이더(5°C 단위), 자주 쓰는 범위 버튼 3개, 습도 조절 여부 + 필요 습도 슬라이더.
- 결과: 눈금 위의 붉은 띠, 장비 줄 상태 글("맞음", "맞는 모델: PL·PSL", "옵션·별도 모델로 가능", "범위 밖"), 아래 장비 카드 필터, 견적 칸에 선택 조건 표시.
- 열충격 시험기(TSA)는 저온/고온 두 구간을 번갈아 노출하는 장비라서 "두 끝 온도가 각각 구간 안에 있을 때" 맞는 것으로 처리.
- 스크립트가 꺼져 있으면 조작부는 숨겨지고, 모든 장비 막대와 카드가 그대로 보인다(`<noscript>` 안내 포함).
- 키보드: 슬라이더 화살표/PageUp/PageDown, 버튼 Tab+Enter. 휴대폰: 슬라이더와 버튼 높이 44px 이상, 눈금은 전체 폭, 장비 이름이 막대 위로 올라감.

## 색 (6)
- 잉크 `#0e1f2b` / 종이 `#f3f5f6` / 흰색 `#ffffff`
- 열 강조 `#c23b1e`(선택 띠, 견적 버튼) / 냉 강조 `#1d5e8c`(저온 값, 옵션 표시, 포커스)
- 눈금 구역(평평한 색 4칸): 영하 `#dbe8f1`, 0~100 `#e9eef1`, 100~200 `#f3e3db`, 200 이상 `#ecc9bb`

## 글꼴
Pretendard (jsDelivr CDN, 실패 시 Noto Sans KR/맑은 고딕). 본문 17px, 큰 제목 clamp(34~62px) 굵기 800, 자간 -0.035em.

## 배치 개념
첫 화면 = 왼쪽 문구와 조작부, 오른쪽 눈금. 아래로 맞는 장비 카드 → 눈금에 올리지 않은 평가 시스템(반도체 AMI/AMR, 어두운 면) → 1981 큰 글자 + 근거 3가지 → 견적(눈금 가장 뜨거운 색 면) → 큰 회사명 바닥글.

## 참고한 스킬 원칙
- frontend-design: 주제(온도)에서 나온 하나의 장치에 대담함을 모으고 나머지는 조용히. 영문 대문자 라벨, 번호, 그라데이션 안 씀. 사용자가 누를 때만 움직임(띠 이동 0.25초).
- Taste: h1 두 줄 이내, 모든 섹션 제목, 좌우 같은 여백, 본문 16px 이상 진한 색, 키보드 포커스 표시, `prefers-reduced-motion` 존중.

## 사실 근거 (research/espec/products/)
각 장비 줄의 HTML 주석에 출처 문서 표기. 수치는 PlatinousJ, SH벤치탑, MTP-101, AR시리즈, TCC시리즈, TSA열충격, HAST, 워크인챔버, 산업용오븐, 배터리장비, 반도체평가시스템 문서에서만.

## 확인 필요
- 습도는 온도마다 쓸 수 있는 구간이 달라 정확한 온습도 선도 확인 필요(화면에도 표시). 현재는 장비의 습도 범위만 비교.
- 산업용 오븐 하한은 "주위온도+20°C"라 눈금은 +20°C로 가정해 그림. 실제 하한은 설치 장소에 따름.
- Platinous J는 모델별 하한(PR -20, PL -40, PSL -70)이 달라 "맞는 모델"을 표시. 옵션 확장(+150/+180°C)은 모델별 상이.
- 회사 주소, 전화, 이메일. 견적 버튼 연결 대상(현재 `#`).
- 확인 못 한 시각 점검: 이 환경에서 브라우저 화면 캡처를 못 해 실제 화면 확인은 사용자 측 열어보기 필요.

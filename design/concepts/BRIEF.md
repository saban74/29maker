# 메인 페이지 디자인 시안 브리프 (2026-11-03)

사용자 요청: "각 스킬을 이용해서 디자인 다시 구성. 장비 실사 사진은 제작사(ESPEC) 홈페이지 사진 참조. 메인은 뻔하지 않은 디자인. 애플 타입 포함 5~7개 시안."

## 공통 조건 (모든 시안)
- 범위: **메인 페이지 1장**만. 각 시안은 `design/concepts/<번호-이름>/index.html` + 같은 폴더의 `style.css`(필요하면 `script.js`). 다른 시안과 CSS를 공유하지 않습니다(각자 완결).
- 회사: 제이에스 엔지니어링 / J&S ENGINEERING, "ESPEC 한국 단독 총대리점", 1981년 설립(45년). 회사 정보는 `research/company/company.md`, 제품은 `research/espec/products/`, 뉴스는 `research/espec/news.md`.
- 메뉴 6개: 회사소개 / 제품소개 / 솔루션 / 기술자료 / 서비스 / 고객지원 + 견적문의. (시안이라 링크는 `#`이어도 됨)
- **장비 사진:** `design/concepts/assets/espec/`의 ESPEC 공식 사이트 사진 12장(목록과 출처: `research/espec/images.md`). 시안 HTML에서는 `../assets/espec/파일명`으로 씁니다.
  - 모두 흰 배경 누끼이고 **해상도가 낮습니다(가로 270~660px).** 원래 크기의 1.2배 넘게 키우지 마세요. 큰 화면을 채워야 하면 사진을 키우지 말고 배경색 면, 큰 글자, 여러 장비 배열로 채우세요.
  - `mtp-101-news.webp`는 왼쪽 위에 수상 로고가 있어 CSS로 잘라(object-position/overflow) 쓰거나 수상 소식에만 씁니다.
  - 건물, 시험실, 산업 현장 사진은 없습니다. 필요한 자리는 시안 분위기에 맞는 자리표시(무엇이 들어갈지 글로 적기)로 둡니다. 외부 사진 링크, 무료 사진 사이트, 지어낸 사진 금지.
  - 페이지 맨 아래 작은 글씨: "장비 이미지 출처: ESPEC Corp. 공식 웹사이트".
- **사실만:** 근거 있는 숫자(1981, 45년, 연 3~4회 세미나, 제품 사양)만 씁니다. 거래처 수, 설치 대수 같은 숫자 지어내기 금지. 모르는 값은 `[확인 필요]`.
- 순수 HTML/CSS/JS, 외부 라이브러리 없이. 글꼴은 Pretendard(jsDelivr CDN) 또는 시스템 글꼴. 휴대폰(390px)에서 가로 넘침 없이.
- 스킬: `.claude/skills/frontend-design/SKILL.md`(필수로 읽기), `.claude/skills/design-taste-frontend/SKILL.md`와 `references/`(원칙 참고, `library/directions.json`·`heroes.json`·`sections.json`은 읽어서 방향 아이디어로 활용 가능. `scripts/*.mjs`는 실행하지 않음).
- **이번 시안은 "뻔하지 않은 메인"이 목표**라서 기존 참고 시안(`design/reference/`) 스타일을 따를 필요는 없습니다. 단 7번 시안만 참고 시안 기반입니다.
- 각 시안 폴더에 `NOTE.md`: 시안 이름, 한 줄 아이디어("이 페이지에서 [회사/장비의 무엇]이 [어떤 장치]가 된다"), 색 4~6개, 글꼴, 배치 개념, 참고한 스킬 원칙, 확인 필요 사항.

## 시안 목록
1. **apple-light (애플 타입 · 밝은)**: 애플 제품 페이지처럼 장비 한 대가 주인공. 흰/연회색 넓은 여백, 큰 제품명과 한 줄 문구, 제품별 타일(밝은/어두운 면 번갈아), 사양 숫자 크게. 메인 첫 화면 주인공은 Platinous J.
2. **apple-dark-pro (애플 타입 · 프로 다크)**: 애플 Pro 제품 페이지처럼 검은 바탕, 장비를 조명처럼 띄우고(배경 원형 빛은 금지가 아니라 절제해서), 거대한 사양 숫자(-70°C, +180°C, 98%rh)가 스크롤에 따라 등장. 반도체·AI 서버 시험 장비 강조.
3. **temperature-axis (온도 축)**: 페이지 전체가 하나의 온도 눈금(-70°C → +300°C)이고, 장비들이 자기 온도 범위 위치에 놓인다. "시험하려는 온도/습도를 고르면 맞는 장비가 표시"되는 한 가지 조작 요소(live thing).
4. **test-report (시험 성적서)**: 신뢰성 시험 성적서·사양서 문서의 질서(표, 문서 번호, 서명란, 도장 느낌)를 웹 메인으로. 45년 = 수많은 시험의 기록이라는 아이디어. 장식 선 남발이 아니라 문서 구조 자체가 디자인.
5. **since-1981 (45년 에디토리얼)**: 잡지 같은 큰 글자 편집 디자인. 1981 TABAI(현 ESPEC) 총판 계약부터 지금까지를 첫 화면과 흐름의 축으로. 연혁의 연도가 큰 글자로, 장비 사진이 시대별로 놓임.
6. **industry-lens (산업 렌즈)**: "무엇을 시험하나요?" 반도체 / 전기전자 / 배터리 / 자동차·모빌리티 / 항공우주·방산 / 소재. 산업을 고르면 첫 화면의 장비 구성과 문구가 바뀌는 메인.
7. **reference-plus (참고 시안 개선판)**: 사용자가 준 참고 시안(`design/reference/*.webp`, 현재 `design/main.html`) 스타일을 유지하면서 ESPEC 실사 장비 사진을 넣고, frontend-design·Taste 원칙(제목 두 줄 이내, 여백 균형, 읽기 쉬운 글자)으로 다듬은 판. 비교 기준용.

# 시안 7. reference-plus (참고 시안 개선판)

**한 줄 아이디어:** 이 페이지에서 ESPEC 실제 장비 사진이 참고 시안의 회색 자리표시를 대신해 "제품 증거"가 된다. 구성과 톤(밝은 사옥 첫 화면, 4개 바로가기, 산업 6칸, 남색 숫자 구역)은 참고 시안 그대로.

## 바뀐 점 (design/main.html 대비)
- 대표 제품 3칸과 제품 카드 5장, 첫 화면 오른쪽, 뉴스 3칸에 ESPEC 실사 장비 사진을 넣음. 사진은 흰 면 위에만 놓고, 글자는 사진 아래에 둠(사진 위 글자와 그라데이션 제거).
- 첫 화면 제목을 3줄에서 2줄로(Reliability for / a better tomorrow). 오른쪽 빈 곳은 Platinous J 사진 패널로 채움 (좌우 균형).
- 본문 글자 16px 이상, 보조 글자 색을 더 진하게. 구역 위아래 여백 112px에서 96px로 줄임.
- 사진은 원본 크기보다 키우지 않음(`max-width:100%` + 자동 크기). MTP-101은 위쪽 수상 로고를 잘라 사용.
- 참고 시안 요소(영문 대문자 라벨, 01~04 번호, → 화살표, 얇은 선, 사진 위 그라데이션 카드)는 유지. 건물·산업 6종 사진은 자리표시 유지.

## 색 (6)
- 잉크 #0B1220, 남색 #101D33, 본문 #1A2230 / 진한 보조 #2E3745, 연회색 #F3F4F6 / #F8F9FA, 강조 #2B5C9E

## 글꼴
Pretendard(본문, jsDelivr CDN) + Inter 계열(영문 제목·숫자). 본문 16px, h1 48px(휴대폰 30px), h2 34px.

## 배치
첫 화면 2열(글 + 장비 사진) → 산업 6칸 → 대표 제품 3칸 + 제품 5칸 → 숫자 구역 → 파트너 → 뉴스 → 카탈로그 안내 → 견적 띠.

## 참고한 스킬 원칙
제목 두 줄 이내, h1 하나와 모든 구역 제목, 좌우 균형, 본문 16px 이상·진한 색, 키보드 포커스, 움직임 줄이기. 참고 시안과 부딪히는 규칙(라벨, 번호, 선, 그라데이션 금지)은 따르지 않음.

## 확인 필요
- 본사 건물 사진 보유 여부, 산업 6종 사진(회사 보유분 또는 사용 허가본)
- ESPEC 사진 사용 허가(출처 표기는 페이지 맨 아래에 있음), TSA 온도 범위, 납품 대수·고객사 수, 전화·주소 등 푸터 정보
- 사진 해상도가 낮아 큰 화면에서는 흰 면 위에 원본 크기로 놓았음

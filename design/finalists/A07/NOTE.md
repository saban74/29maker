# A07 최종 후보 (apple.com 구조) - 3페이지

파일: `index.html`, `products/platinous-j.html`, `about.html`, `style.css` (세 페이지 공통, JS 없음). 사진은 `../../concepts2/assets/` 참조.

## 원본에서 이어받은 규칙
- 색: 흰 #fff / 연회색 #f5f5f7(바탕) / 먹색 #1d1d1f(글) / 보조 글 #515154 / 링크 파랑 #0066cc(강조 하나) / 검정 #000 / 어두운 면 #161618. 사진 배경 회색 #d9dbdc.
- 글꼴: Pretendard 한 종. 큰 제목 800, 자간 -0.045em, `word-break: keep-all`.
- 버튼: 알약 하나. 채운 것(주) + 윤곽(보조). 어두운 면에서는 밝은 파랑(#0a84ff / #6cb2ff).
- 면: 위아래로 쌓이는 화면 폭 면 사이에 12px 틈(연회색이 비침). 밝음/어두움이 면 단위로 바뀜. 카드는 둥근 22px, 그림자 없음.
- 배너: 제품 사진이 배경, 제품명 + 한 줄 + 링크 둘은 사진 위쪽 회색 여백. 휴대폰에서는 글 위, 사진 아래 56%이고 사진 윗부분이 배너 바탕색으로 녹음.

## 하위 페이지에 적용한 방법
- 제품 상세(apple 제품 페이지): 길 표시 + 총대리점 띠 -> 위에 붙는 안쪽 메뉴(제품명, 개요/특징/주요 사양/지원/자료/관련 제품, 견적 문의 알약) -> 배너(single-a 사진, 버튼 3개) -> 핵심 수치 3개(큰 글씨 타일) -> 검은 면 용도 -> 배너(single-b, ECO) -> 반반 타일 특징 -> 사양표(가로 스크롤, 키보드 이동 가능) -> 검은 면 규격·수상 -> 지원 흐름 5단계 -> 자료 -> 관련 제품 3장 -> 검은 견적 띠. 사양은 `research/espec/products/PlatinousJ.md` 값만.
- 회사소개(apple 회사·환경 페이지): 검은 글자 히어로 -> 숫자 4개 -> 대표 인사말(초안 표시) -> 총대리점 배너(lineup 사진) -> 검은 면 기술 협력 4개 -> 연혁(연대별 흰/검정 면) -> 협력사·거래처(글자만) -> 오시는 길(주소·전화·이메일 [확인 필요], 지도 자리 회색 상자) -> 검은 띠.
- 사진 회색과 배너 바탕: 모든 사진 배너 바탕을 `--photo`(#d9dbdc)로 통일. 사진 위쪽 회색이 더 어두운 편(약 #909395)이므로 글은 먹색 #1d1d1f로 두었고, 브라우저에서 실제 이음새 눈 확인 필요.

## 확인 필요
- 사진이 원본 가로를 넘게 커지지 않도록 1760px 이상 초광폭 화면에서는 배너 사진이 1.2배를 넘을 수 있음(single-a 1467px 기준).
- 연혁 중 판독 불가 항목(1995, 1999, 2003 LED, 2004) 제외. 사양표 PL-ECO 내용적, 외형 치수·전원, 보증 국내 조건, 지원 5단계 범위, 주소·전화·이메일.
- 회사 사진(건물, 직원)이 없어 회사소개는 장비 사진과 글자 중심. 로고·글꼴 미확정(글자 워드마크 J&S ENGINEERING).

# AW05 최종 후보: 메인 + 제품 상세 + 회사소개

파일: `index.html`, `products/platinous-j.html`, `about.html`, `style.css`(원본 `_base-aw2.css`와 `05/style.css`를 합치고 하위 페이지 부품을 더함). 사진은 `../../concepts2/assets/`를 상대 경로로 씀.

## 이어받은 디자인 규칙
- 색: 바탕 #e8e8e8, 첫 화면·큰 글자 구역 #c9c9c9, 어두운 구역 #0a0a0a, 중간 글자 #5d5f63, 황동 #a8864a(밑줄과 키보드 포커스 한정). 표 줄무늬 #dcdcdc 한 단계만 추가.
- 글꼴: 큰 영문·숫자는 Michroma, 한글과 본문은 Pretendard. 글자 크기는 "화면 폭에 비례하는 큰 글자"와 "16px 작은 글자" 두 가지 위주(원본은 15px였으나 읽기 편하게 16px로 올림).
- 큰 글자 줄은 회색에서 흰색으로 네 단계로 깊이를 냄(원본의 -70°C / +200°C / 98%rh / 45년 방식).
- 여백: 좌우 24px(휴대폰 20px), 구역 위아래 130~150px, 설명 기둥 230~260px.
- 버튼: 각진 사각형 하나(검정 채움, 어두운 바탕에선 흰 채움) + 황동 밑줄 링크. 그림자, 둥근 모서리 없음.
- 선 대신 바탕색 단계로 구분(표도 줄무늬).

## 장치: 장비가 글자의 가운데를 가린다
- `.stage`는 사진과 같은 비율(1467:988) 상자이고, 글자(SVG)와 장비 모양 자르기(`.cut`의 clip-path)가 모두 그 상자 안의 퍼센트 값. 그래서 화면 폭이 바뀌어도 사진과 같이 커지고 줄어 어긋나지 않음.
- 글자는 원본의 `12cqw` 글자 대신 SVG `textLength`로 상자 폭 92%에 정확히 맞춤. Michroma 실제 폭이나 글꼴 로딩 지연에 상관없이 위치가 고정됨.
- 휴대폰(760px 이하)에서는 상자를 화면 폭 1.8배로 줄여 장비가 화면을 다 덮지 않고 양옆에 글자 끝이 보이게 함. 위아래는 마스크로 바탕 회색과 이어 붙임. 1761px 이상 큰 화면은 좌우를 마스크로 이어 붙임(사진을 1.2배 넘게 키우지 않으려고 상자 최대 폭 1760px).
- 제품 상세: 같은 장치 + 이름/경로/버튼. 개요의 시리즈 사진은 사진을 multiply로 얹어 뒤의 "J SERIES"를 장비가 가림.
- 회사소개: "J&S"를 같은 방식으로, 장비가 &를 가려 "J [장비] S"로 읽힘. 아래에는 원본처럼 "1981 / 45년" 큰 글자와 연혁(10년 단위 글자 + 작은 목록).

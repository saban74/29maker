# R06 모노크롬 실버 (최종 후보 확장판)

원본: `design/concepts2/R-reference/R06/` (수정하지 않음). 공통 CSS `style.css`는 원본 `_base-r2-b.css`와 R06 `style.css`를 합치고 하위 페이지용 부품을 더한 것입니다. 세 페이지가 함께 씁니다.

## 이어받은 디자인 규칙
- **색:** 은회색 #9A9EA1(첫 화면·페이지 머리), 연회색 #F0F1F1 / #E1E3E4, 패널 #F7F7F7, 잉크 #0B0C0D, 흑연 띠 #0E0F10, 선 #BFC3C6. 강조색 없음(강조도 검정). 노란색은 `[확인 필요]` 표시만.
- **글꼴:** Pretendard(본문, 16px, 줄간격 1.7, keep-all) + Inter 300(영문 큰 제목, 대문자, 자간 .05em). 구역 제목 h2는 Pretendard 600.
- **버튼:** 각진 사각(모서리 0), 검정 채움 / 검은 테두리(ghost) / 흰 채움(검은 띠 위). 링크는 밑줄 + "→".
- **사진:** 모두 흑백(grayscale + 약한 contrast). 누끼 이미지는 multiply로 패널에 얹음. 원본 가로 1.2배 넘게 키우지 않음.
- **선:** 제목 위 줄(eyebrow, 페이지 머리 태그), 표·목록 위 줄, 사양 흐름의 세로 줄.
- **움직임:** 메인 첫 사진 한 번 자리 잡기만. 움직임 줄이기면 꺼짐.
- **메뉴:** 6개 + 견적문의 버튼. 메인 첫 화면의 영문 큰 문구, 01~04 바로가기 유지.

## 하위 페이지에 적용한 방법
- **페이지 머리(`.page-head`)**: 메인 첫 화면의 윗부분(은회색 면 + 태그 줄 + 영문 큰 제목 + 오른쪽 부제)을 그대로 씀. 제품 상세는 경로 표시 줄 + 총대리점 표시로 대신함.
- **제품 상세**: 기획서 4-4 순서(머리·핵심 수치 3개·체크 목록·버튼 3개, 탭 줄, 용도, 특징, 사양표, 규격·수상, 지원 흐름, 자료, 관련 제품, 견적 띠). 탭 줄은 흑연 띠로 상단 고정. 핵심 수치는 Inter 300 큰 숫자 + 세로 가는 선. 사양표는 흑연 머리 + 가는 선, 모바일에서는 가로 스크롤. 지원 흐름은 순서가 있는 내용이라 번호를 씀. 사양 값은 `research/espec/products/PlatinousJ.md`만 사용.
- **회사소개**: 인사말(초안 표시) / 흑연 띠 숫자(1981, 1994, 45년, 연 3~4회) / 연혁 표 / 기술 협력 / 거래처 글자만 / 오시는 길. 판독된 연혁만 실음.
- **확인 필요:** 대표 사진, 지도, 주소·전화, 납품 수·고객사 수, 지원 흐름 단계별 범위, 산업별 적합 모델, 컨트롤러 확대 사진, 초에너지절약 저온형 내용적 상세.
- 메인에서 고친 점: 메뉴·바로가기·"회사소개 보기" 링크를 실제 페이지로 연결, 이미지 경로를 finalists 기준으로 바꿈, 불필요한 중복 id(`support`) 정리, 확인 필요 칸 줄바꿈 정리.

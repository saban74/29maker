# S1-sstr: SSTR - Friction Reduction 영감 (Awwwards Site of the Day)

공통 파일: `_base.css`(토큰, 레일, 셀, 점 차트, 버튼 기본형), `_base.js`(점 차트 그리기, 숫자 올라가기). 4개 시안은 모두 이 둘을 불러온 뒤 자기 `style.css`로 도형과 구성을 바꾼다. 정적 확인은 각 폴더 `index.html`을 브라우저로 열면 된다.

- 01 흑연 챔버 창: 어둠 속 워크인 챔버 전면 사진, 절단 모서리 버튼, 온도 눈금자, 검열 막대 등장.
- 02 로더 칸과 원형 문: 4칸 모자이크 첫 화면, 밝은 톤, HAST 원형 문이 도형.
- 03 큰 숫자 장부: 회색 스튜디오 사진 + 아주 큰 가는 숫자와 점 차트가 좌우로 엇갈림, 문 손잡이 홈이 도형.
- 04 온도 곡선 고정 장면: 스크롤로 온도 곡선이 그려지는 고정 장면, 신호 램프 3칸이 도형.

원본에서 쓰지 않은 것: 원본 로고, 문구, 팔각형, 3D 렌더, 주황 값 그대로(#f4600c로 변경).

# S3-longbow (Awwwards Site of the Day, longbow 영감)

공통: `_base.css`(4열 헤어라인 그리드, 교차점 노드, 압축 마키, 세리프 제목, 사각 버튼, 휴대폰 2열). 각 폴더 `index.html` + `style.css` + `NOTE.md`.

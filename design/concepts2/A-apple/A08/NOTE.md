# A08 디테일 클로즈업

- **한 줄 아이디어:** "정밀함은 가까이서 보입니다." 장비를 잘라 보여 주어(문, 손잡이, 조작부, 창) 정밀함을 이야기한다.
- **다른 시안과 다른 점:** 사진 크롭이 주인공. CSS `background-size/position`으로 원본 픽셀 그대로(확대 없음) 일부만 보여 준다. 검은 첫 화면의 크롭은 가장자리를 부드럽게 지워 검은 바탕에 녹이고, 밝은 구역에는 높이가 다른 6장 크롭을 엇갈려 놓았다.
- **색:** 검정 #050608(바탕) / 은백 #f3f3f1(글자) / 석고 #e8e8e4(밝은 구역) / 회색 #a4a8ad(보조) / 장비 LED 초록 #53d68f(점과 밑줄 하나)
- **글꼴:** Pretendard 한 종. 800, 자간 -0.055em.
- **쓴 사진:** walk-in-tbe-dark(첫 화면 크롭), platinous-j-single-b, tsa-pair, hast-ehs-lineup, walk-in-tbe, ar-series-pair, platinous-j-lineup(크롭), hast-ehs-door-detail, tsa-cutaway-dark(작은 원본 그대로).
- **움직임:** 크롭 사진이 화면에 들어오면 한 번 천천히 드러남(줄이기 설정에서는 처음부터 보임).
- **확인 필요:** 크롭 좌표는 눈대중이라 브라우저에서 잘림 위치 확인 필요. 캡션의 값은 research 근거(±1.5°C, 1,000V/120pins, 1mΩ). 실물 방문 확인 가능 여부, 주소·전화·이메일.

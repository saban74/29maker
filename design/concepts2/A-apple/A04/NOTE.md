# A04 어떤 시험이 필요하세요? (비교형)

- 한 줄 아이디어: 질문 하나로 시작해 화면을 반으로 나눠 열충격 TSA와 HAST EHS를 마주 세운다.
- 다른 시안과 다른 점: 좌우 대칭 두 면 + 가운데 "또는". 아래에 실제 비교표(table)와 "둘 다 아니라면" 길 안내.
- 색: 바탕 #f4f4f6 / 좌 면 #e9eaed / 우 면 #ececef / 글자 #1d1d1f / 강조 #0a64c8 / 마감 #111113
- 글꼴: Pretendard 하나. 제목 700, 중앙 정렬.
- 쓴 사진: hires/tsa-pair, hast-ehs-lineup
- 움직임: 두 사진이 양옆에서 살짝 들어와 자리 잡음(한 번).
- 확인 필요: TSA의 습도 항목(카탈로그 표기 없음으로 적음), 주소/전화/이메일. 온도는 TSA-ES, EHS-412 기준.

# A03 장비 가족 가로 갤러리

- 한 줄 아이디어: 첫 화면부터 ESPEC 장비 가족이 옆으로 넘어간다. 카드 한 장이 곧 사진 한 장.
- 다른 시안과 다른 점: 제목 아래 바로 가로 스크롤 카드(스냅, 이전/다음 버튼, 방향키). 글은 사진 위쪽 빈 회색 자리에 얹음. 두 번째 가로 줄은 흰 누끼 소형 장비.
- 색: 바탕 #e9e9ec / 밝은 면 #f5f5f7 / 흰 #fff / 글자 #1d1d1f / 링크 #0a64c8 / 마감 #111113
- 글꼴: Pretendard 하나. 제목 700.
- 쓴 사진: hires/platinous-j-lineup, tsa-pair, hast-ehs-lineup, walk-in-tbe-side-door, ar-series-pair. web/ 누끼 5장(sh, tcc, 오븐, 배터리, AMI).
- 움직임: 첫 카드 사진이 자리 잡듯 한 번. 카드 호버 시 사진 확대.
- 확인 필요: AR 시리즈 설명 문구(사양 근거 없이 "용량이 큰 시험품" 수준으로만 적음), 주소/전화/이메일.

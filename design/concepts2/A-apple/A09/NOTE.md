# A09 스토어형

- **한 줄 아이디어:** "필요한 장비를 담고, 견적을 받으세요." 장비를 장바구니처럼 담아 견적을 받는 흐름이 메인의 중심.
- **다른 시안과 다른 점:** 첫 화면이 이미 선택 화면(제목 + 3단계 흐름 + 시험 목적 칩 + 장비 카드). 담으면 카드에 초록 테두리와 "담김", 아래에 개수 바가 올라오고, 견적함 목록과 조건 입력 폼으로 이어진다. 유일하게 JS로 동작(담기, 거르기).
- **색:** 연회색 #f5f5f7(바탕) / 흰 카드 #ffffff / 먹색 #1d1d1f(글자) / 흑연 #232326(버튼) / 담김 초록 #17744a와 #dff1e7(상태 표시에만)
- **글꼴:** Pretendard 한 종.
- **쓴 사진:** web/ 누끼 12장 중 9종(Platinous J, TSA, HAST, 워크인, SH, AR, 오븐, AMI·AMR, 배터리). 카드 안 연회색 판 위에서 multiply로 녹임.
- **움직임:** 장비를 담으면 개수 바가 아래에서 올라옴. 그 밖에는 버튼 눌림 반응만.
- **확인 필요:** 폼은 화면용(전송 없음), 제출 방식과 회신 시점. 카드의 한 줄 문구 일부(AR, SH, 오븐)는 제품 문서 기준 요약. 주소·전화·이메일.

# S5-02 얼음

- 한 줄 아이디어: 밝은 얼음색 바탕에 열충격 시험기를 크게 세우고, 가운데 남색 카드의 점선 그래프(고온 +200 ~ 저온 -70°C)를 사각 마커가 오가게 한다.
- 원본에서 빌린 원리: 밝은 구간의 "통계" 구성(왼쪽 두 줄 제목과 작은 문단, 가운데 3:4 남색 카드와 점 격자 그래프와 하단 버튼, 오른쪽 옅은 세 줄), 얼음색~코발트 한 계열, 점선 추적 상자, 사각 버튼 + 화살표 사각형, 굵지 않은 제목.
- 바꾼 점: 주가형 상승 그래프 대신 열충격 시험의 온도 주기(사양 값만). 오른쪽 세 줄은 TSA의 실제 특징(고정 시험 공간, 온도 회복, 원격 감시). 회색 스튜디오 사진은 multiply와 가장자리 마스크로 얼음색에 녹임.
- 다른 시안과 다른 점: 밝은 시안. 첫 화면이 글자 왼쪽 + 장비 오른쪽의 분할. 대표 장비는 TSA(파란 문이 팔레트와 맞음). 표(사양표)가 주인공인 구간이 있음.
- 색: 얼음 #e6edf7, 한 단계 진한 얼음 #d9e3f3, 남색 #0a1730, 코발트 #0e3f97, 신호 파랑 #1f6bff, 흰색.
- 글꼴: Pretendard 하나.
- 사진: tsa-pair, tsa-single, platinous-j-single-a, hast-ehs-twin, ar-series-pair, walk-in-tbe.
- 사양 출처: research/espec/products/TSA열충격.md 등. 그래프는 ES형 값(+60~+200 / -70~0)을 단순화한 그림이며 실제 시험 곡선이 아님.
- 확인 필요: 주소·전화·이메일, 링크. 상자 표시 모델명과 사진 속 장비의 대응(사진에 TSA-73ES, TSA-203ES 표기가 보임).

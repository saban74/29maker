# S5-04 장

- 한 줄 아이디어: 한 대(Platinous J)를 오른쪽에 놓고 점선 상자가 관찰창, 표시 화면, 본체를 차례로 잡는다. 스크롤하면 바탕이 남색 → 얼음색 → 코발트 → 검정으로 장(chapter)마다 바뀐다.
- 원본에서 빌린 원리: 고정된 하나의 바탕 층이 구간마다 색을 바꿔 가며 이어지는 것, 장비를 오른쪽에 두고 점선 상자로 추적하는 것, 모서리 사각 마커, 굵지 않은 제목, 사각 버튼 + 화살표 사각형, 이름이 큰 푸터.
- 바꾼 점: 암호화폐 지표 대신 Platinous J 계열표(실제 사양)와 "ECO형 최대 70% 절감" 큰 숫자. 연혁은 순서가 있는 내용이라 가로 띠(순서대로 넘김)로. 회색 사진은 남색 위에서 부드러운 스포트라이트처럼 보이도록 가장자리를 흐리게 함.
- 다른 시안과 다른 점: 바탕색이 스크롤로 바뀜(자바스크립트, 없으면 구간별 고정색). 상자가 스스로 돌아감(움직임 줄이기 설정이면 모두 정지 표시). 연혁 가로 띠.
- 색: 남흑 #050c17, 얼음 #e6edf7, 코발트 #0e3f97, 검정 #000, 신호 파랑 #1f6bff.
- 글꼴: Pretendard 하나.

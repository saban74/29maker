# S5-03 무대

- 한 줄 아이디어: 화면 폭 회색 "무대"에 HAST 시험기를 세우고, "구조선으로 보기"를 누르면 사진이 윤곽선만 남은 파란 도면으로 바뀐다(원본의 "덮개가 열리며 와이어프레임이 되는" 장면을 해석).
- 원본에서 빌린 원리: 점선 추적 상자와 사각 마커, 사진 → 와이어프레임 전환, 얇고 아주 큰 숫자, 라벨·제목·문단 2열 목록, 이름 크기가 변하는 색인(비활성은 회색으로 흐림), 사각 버튼 + 화살표 사각형, 가로 전체 푸터 이름.
- 바꾼 점: 윤곽선은 SVG 필터(feConvolveMatrix)로 만든 실제 사진의 윤곽 — 외부 라이브러리 없음. 필터 효과는 브라우저에 따라 거칠 수 있으니 확인 필요. 세 가지 시험 조건(온도·습도·압력) 숫자는 EHS 사양 그대로.
- 다른 시안과 다른 점: 사용자가 누르는 장치(전환 버튼)가 있음. 사진이 화면 폭 회색 띠. 제품 색인이 큰 글자 목록.
- 색: 남흑 #050c17, 코발트 #0e3f97, 무대 회색 #cdd1d6(사진 배경에 맞춤), 얼음 #e6edf7, 신호 파랑 #1f6bff.
- 글꼴: Pretendard 하나.
- 사진: hast-ehs-lineup(1268px, 무대에서 1.0배 이하로 사용).
- 사양 출처: research/espec/products/HAST.md. EHS-222M-L 소식(2025-11-06), AMI-SPM 연동(2026-08).
- 확인 필요: 주소·전화·이메일. 윤곽선 전환이 모바일 Safari에서 정상인지.

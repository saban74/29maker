# S5-01 홀

- 한 줄 아이디어: 어두운 시험실의 워크인 챔버 위에 머신 비전 점선 상자를 얹고, 글자는 화면 네 모서리에 붙인다. 이어서 왼쪽 주장이 하나씩 밝아지고 오른쪽 장비가 바뀐다(원본 구조에 가장 가까움).
- 원본에서 빌린 원리: 큰 사진 위 모서리 배치(제목 좌상단, 버튼 두 개 세로, 하단 소개문과 소식 카드), 점선 추적 상자와 모서리 사각 마커, 사각 버튼 + 붙은 파란 화살표 사각형, 굵지 않은 제목, 고정 장비 + 스크롤 주장 목록(비활성 줄 40%로 흐림), 검정 패널 + 모서리 마커 + 점선 도면, 가로로 꽉 찬 이름이 아래에서 잘리는 푸터.
- 바꾼 점: 암호화폐 문구와 거래소 배지 대신 "ESPEC 한국 단독 총대리점" 배지. 3D 렌더 영상 대신 카탈로그 사진(`walk-in-tbe-dark.jpg`). 밝은 구간의 회색 스튜디오 사진은 multiply로 얼음색에 녹임. 점선 도면은 워크인 챔버 정면.
- 다른 시안과 다른 점: 가장 원본에 충실. 어두운 전체 화면 히어로 + 고정 장비 목록.
- 색: 남흑 #050c17, 코발트 #0e3f97, 신호 파랑 #1f6bff(마커·화살표만), 얼음 #e6edf7, 크롬 #a7a8ab, 흰색.
- 글꼴: Pretendard 하나(제목 400, 라벨 700 자간).
- 사진: walk-in-tbe-dark, platinous-j-lineup, tsa-pair, hast-ehs-lineup, ar-series-pair.
- 추적 상자 값 출처: research/espec/products/ (워크인 E 시리즈 EBE -40~+80°C·10~95%rh·4.2~52.7m³, TSA-ES, EHS, AR, Platinous J).
- 확인 필요: 주소·전화·이메일, 뉴스 카드 링크, 소식 구독 양식. 추적 상자의 모델명과 사진 속 장비의 일대일 대응(사진은 대표 이미지).

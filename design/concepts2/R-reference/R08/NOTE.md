# R08 히어로 슬라이드 3장

- **한 줄 아이디어:** 첫 화면에서 대표 장비 세 가지(Platinous J, TSA, 워크인)를 차례로 보여 주는 남색 무대. 제목 "Reliability for a better tomorrow"는 슬라이드가 바뀌어도 고정.
- **다른 시안과 다른 점:** 유일한 슬라이드형. 머리말까지 짙은 남색, 오른쪽 58%가 사진 창, 왼쪽 아래에 장비명·사양·한 줄 설명·버튼. 
- **조작:** 이전 / 다음 / 일시정지(재생) 버튼, 1·2·3 진행 막대(누르면 이동), 왼쪽·오른쪽 화살표 키와 Home/End(무대에 초점이 있을 때). 마우스를 올리거나 키보드 초점이 있으면 잠시 멈춤.
- **움직임 줄이기:** 설정이 켜져 있으면 자동 넘김이 아예 꺼지고(일시정지 버튼도 숨김) 수동으로만 넘김. 자바스크립트가 없으면 첫 슬라이드만 보임.

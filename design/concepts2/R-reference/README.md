# R. 참고 시안 계열 10종

참고 시안(메뉴 6개, 큰 첫 화면 + 영문 문구, 01~04 바로가기, 산업 6칸, 대표 제품, 숫자 구역, 파트너, 뉴스, 견적 띠)의 구성을 지키고 첫 화면과 분위기를 달리한 10종. 열 때는 각 폴더의 `index.html`.

| 시안 | 설명 |
|---|---|
| R01 ~ R05 | 다른 디자이너 작성 |
| R06 | 모노크롬 실버. 흑백 Platinous J 사진, 은회색 바탕, 가는 선. |
| R07 | 솔루션 우선. 첫 화면이 한국어 제목 + 산업 6칸(장비 한 줄씩). |
| R08 | 히어로 슬라이드 3장(Platinous J / TSA / 워크인). 이전·다음·일시정지, 화살표 키, 움직임 줄이기 시 자동 넘김 꺼짐. |
| R09 | 기업 잡지형. 거대한 "45년", 세리프 제목, 연혁 하이라이트. |
| R10 | 스위스 그리드. 12열, 아주 큰 제목, 코발트 사각형 하나. |

- R06~R10 공용 CSS: `_base-r2-b.css` (R01~R05의 `_base-r2.css`와 별개)
- 사진: `../assets/hires/`(카탈로그 추출), `../assets/web/`(웹사이트 누끼). 출처 문구는 각 페이지 맨 아래.

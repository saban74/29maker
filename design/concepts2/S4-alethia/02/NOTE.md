# S4-02 뜨거움과 차가움

- 한 줄 아이디어: 열충격 시험기의 양 끝 온도(+200°C, -70°C)가 곧 화면의 글자와 눈금이 된다.
- 다른 시안과 다른 점: 장비 두 대(TSA-73ES, TSA-203ES)에 각각 조준선. 여러 장비의 온도 범위를 하나의 눈금자 위에 올려 비교하는 "온도 눈금" 구역이 서명 장면. 마지막은 실제 사양표.
- 색: 바탕 `#090c13`, 글자 `#f0f1f3`, 밝은 구역 `#d8dadc`, 먹 `#10161a`, 강조 연한 호박색 `#ffd7a1`(눈금 양끝 사각형, 조준선 모서리, 푸터 큰 글자)
- 글꼴: Pretendard + 시스템 고정폭(눈금 숫자, 태그)
- 사진: `tsa-pair.jpg`(원본 2000px), `tsa-cutaway-dark.jpg`(482px, 원본 크기 이내로만 표시)
- 원본(Alethia)에서 빌린 원리: 조준선+데이터 태그, 모서리 글자(제목 왼쪽 위, 설명 왼쪽 아래, 큰 숫자 오른쪽 아래), 어두움 구역과 밝은 구역 교차, 작은 사각형에만 쓰는 강조색, 큰 푸터 워드마크, "측정"을 시각 주제로.
- 바꾼 점: 자연 풍경 대신 시험 온도라는 측정 자체를 그림(눈금자). 호박색은 원본의 라임과 달리 "열풍". 유리 카드 없음.

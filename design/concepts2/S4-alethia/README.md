# S4-alethia (Awwwards SOTD "Alethia" 영감)

공통: `_base.css`(조준선, 태그, 모서리 배치, 푸터 워드마크), `_common.js`(스크롤 등장).
각 폴더: `index.html`, `style.css`, `NOTE.md`.

- `01/` 밤의 챔버: 검은 사진 속 워크인 챔버, 얼음색 사각형, 서랍형 사양 목록.
- `02/` 뜨거움과 차가움: TSA 열충격, +200/-70 숫자, 온도 눈금자, 호박색.
- `03/` 스튜디오 회색: 밝은 첫 화면, Platinous J와 AR, 먹색 조준선, 청보라.
- `04/` 둥근 문: HAST 원형 조준선, 온도·습도·압력 3값, 안지름 원, 청록.

주의: 이 환경에서는 화면을 열어 확인하지 못했습니다. 조준선 좌표는 사진을 보고 맞춘 값이라 브라우저에서 한 번 확인이 필요합니다.

# S2-coffeetech (Awwwards SOTD, CoffeeTech 영감) 4종

공통: `_base.css`(공통 바탕), `script.js`(화면에 들어올 때 한 번 드러내기). 모두 한 글꼴(Pretendard)이며 강조색은 로고 마크와 주 버튼에만 씁니다.

- 01 호박색 가운데 포스터: "혹한. 폭염. 습기." 뒤, 워크인 챔버 어두운 사진이 어둠에서 떠오르는 원본에 가장 가까운 해석.
- 02 밝은 왼쪽 포스터: "ESPEC / 한국 / 총대리점", Platinous J 라인업이 커튼처럼 열리고 제품은 큰 이름 목록, 청록 강조.
- 03 숫자 포스터: "-70°C / +180°C / 98%rh" 오른쪽 정렬, AR 시리즈가 불 켜지듯 밝아지고 시험 목적별 3열 안내, 얼음색 강조.
- 04 계단식 포스터: "작은 / 벤치탑부터 / 워크인까지", HAST가 원형으로 열리며 드러나고 가로 스냅 제품 줄과 연혁, 연두 강조.

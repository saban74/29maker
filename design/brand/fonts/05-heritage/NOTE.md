# 견본 5. 45년 전통형 (Instrument Serif / Sans + Noto Serif KR / Pretendard)

- 분위기: 깊은 남색 면과 밝은 회백색 면, 놋쇠색 포인트. 세리프 제목, 산세리프 본문. 첫 화면에 1981과 2026을 크게.
- 글꼴: Instrument Serif, Instrument Sans, Noto Serif KR (Google Fonts) + Pretendard Variable (jsDelivr). 모두 SIL OFL.
- 로딩: Google `Instrument+Sans:wght@400..700 & Instrument+Serif & Noto+Serif+KR:wght@500;700`, jsDelivr `orioncactus/pretendard@v1.3.9 ... pretendardvariable-dynamic-subset.min.css`
- 참고 사례: Cochran branding, Hellomatik website (fontsinuse).
- **주의:** jsDelivr 로딩 글꼴(Pretendard)은 이 환경 미리보기에서 대체 글꼴로 보일 수 있음. 제목의 Noto Serif KR은 Google Fonts라 정상 표시.
- 단점: 글꼴 4개로 로딩이 가장 무거움. Noto Serif KR은 한글 용량이 커서 실제 제작 시 사용 굵기를 줄이는 것을 권함.

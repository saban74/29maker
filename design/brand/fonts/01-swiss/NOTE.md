# 견본 1. 스위스 정밀형 (Inter + Pretendard)

- 분위기: 흰 바탕, 검정 글자, 파랑 하나. 큰 제목과 여백으로 위계를 만들고 장식은 없음.
- 글꼴: Inter (Google Fonts) + Pretendard Variable (jsDelivr). 둘 다 SIL OFL.
- 로딩: Google Fonts `family=Inter:wght@400;600;700`, jsDelivr `orioncactus/pretendard@v1.3.9 ... pretendardvariable-dynamic-subset.min.css`
- 참고 사례: NextOre, Path Robotics (fontsinuse). 빌린 점은 index.html 맨 아래.
- **주의:** jsDelivr 로딩 글꼴(Pretendard)은 이 환경 미리보기에서 대체 글꼴로 보일 수 있음. 실제 인터넷 환경에서는 정상 로딩됨.
- 사양표 숫자는 `font-variant-numeric: tabular-nums`로 줄 맞춤.

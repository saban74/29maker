# 05 순환 (방향 E. 화살표·순환 흐름)

## 방향
S자를 두 개의 고리로 보고 각 끝에 화살촉을 달았습니다. "들여오고, 설치하고, 계속 관리한다"는 순환형 서비스를 보여 줍니다.

## 참고한 logobook 사례와 빌린 원리 (모양은 따라 그리지 않음)
- Imatran Voima (https://logobook.com/logo/imatran-voima/): 선이 원을 돌다가 화살표로 이어지는 흐름.
- Giropais (https://logobook.com/logo/giropais/): 글자 모양 자체를 화살표로 활용.
- 화살촉이 원을 닫으려는 방향을 가리키게 해서 "닫히지 않고 계속 돈다"는 느낌을 줍니다. 화살표 크기는 작게 눌러 물류회사처럼 보이지 않게 했습니다.

## 형태의 의미
- 위쪽 고리: 수입과 설치. 아래쪽 고리: A/S와 정기 점검.
- 두 고리가 S로 이어짐: 고객과 함께 계속 돌아가는 관계, 45년.

## 색
- 주색 딥 그린 `#1F7A4D` (근거: 안정, 지속, "이상 없음"의 신호색. 기존 파랑에서 가장 멀어 변화가 분명함)
- 글자 보조 `#2B3644`, 어두운 바탕용 `#4FC48A`
- 흑백: 한 색이라 그대로 성립.

## 최소 크기
- 심볼 16px (화살촉이 작아져도 S 형태는 유지), 가로형 가로 120px.

## 확인 필요
- J 글자는 심볼에 없음 (워드마크에 의존).
- 새로고침(리프레시) 아이콘처럼 보일 수 있어 웹에서 버튼으로 오해될 가능성 확인.
- 초록은 기존 파랑 이미지와 가장 다름. 회사 의견 확인.
- 영문 표기 J&S / JS 확인, 글꼴 윤곽선 변환 필요.

# 골프 내기 정산 앱 (기본 구조)

휴대폰으로 **4명이 같이** 스코어를 입력하면 매 홀 내기 금액, 전반·후반·최종 정산이 바로 나오는 앱입니다.
PC용 **골프장 관리 프로그램**으로 홀별 그린 위치를 등록하면 GPS로 그린까지 거리도 볼 수 있습니다.

## 폴더 구성

| 위치 | 하는 일 |
|---|---|
| `app/` | 휴대폰 앱 (스코어 · 거리 · 정산 화면) |
| `app/betting.js` | 내기 계산 규칙 (타당, 양파 상한, 버디 보너스, 배판, 스킨스, 송금표) |
| `app/geo.js` | GPS 거리 계산 |
| `app/sync.js` · `app/config.js` | 저장과 4명 공유 |
| `app/courses/` | 골프장 정보 파일 (관리 프로그램에서 만든 JSON) |
| `admin/` | PC용 골프장 관리 프로그램 (지도에서 그린 앞/중앙/뒤 찍기) |
| `supabase/schema.sql` | 4명 공유용 서버 표 만들기 |
| `test/betting.test.mjs` | 내기 계산 자동 검사 (`node golf-app/test/betting.test.mjs`) |

## 안드로이드·아이폰 둘 다 되나요?

**됩니다.** 이 앱은 "웹앱(PWA)"이라서 하나로 만들면 두 휴대폰에서 모두 열립니다.
- 안드로이드(크롬): 주소를 연 뒤 메뉴 → **홈 화면에 추가**
- 아이폰(사파리): 공유 버튼 → **홈 화면에 추가**

나중에 플레이스토어·앱스토어에 정식으로 올리고 싶으면, 같은 코드를 "앱 포장(안드로이드 TWA, 아이폰 Capacitor)"만 해서 올릴 수 있습니다. 안드로이드가 더 쉽고 등록비도 싸서(1회 25달러) 먼저 하는 걸 추천합니다. 아이폰은 연 99달러이고 심사가 더 까다롭습니다.

## 내 컴퓨터에서 미리 보기

```bash
cd golf-app
python3 -m http.server 8765
```
- 휴대폰 앱: http://localhost:8765/app/
- 관리 프로그램: http://localhost:8765/admin/

※ 휴대폰 GPS는 **https 주소**에서만 동작합니다. 실제 사용은 Netlify 같은 곳에 올린 뒤 하세요.

## 4명 공유 켜기 (지금은 "혼자 모드")

지금은 기록이 그 휴대폰 안에만 저장됩니다. 4명이 각자 폰에서 같은 라운드를 보려면 무료 서버(Supabase)가 필요합니다.
1. supabase.com 에서 무료 프로젝트 만들기
2. SQL Editor 에 `supabase/schema.sql` 내용을 붙여넣고 Run
3. Project Settings → API 의 **URL** 과 **anon key** 를 `app/config.js` 에 넣기

이후에는 한 사람이 라운드를 만들고 **참여 코드(6자리)** 를 카톡으로 보내면, 나머지 3명이 코드로 들어와 실시간으로 함께 입력·확인합니다.
각 칸(한 사람의 한 홀)을 따로 저장하기 때문에 동시에 입력해도 서로 덮어쓰지 않습니다.

## 골프장 등록하는 법 (PC)

1. `admin/` 을 열고 골프장 이름으로 검색 → 지도 이동
2. **OpenStreetMap에서 자동 불러오기**를 눌러봄 (그려진 골프장이면 홀·그린이 채워짐)
3. 없거나 틀린 홀은 표의 [앞]/[중앙]/[뒤] 버튼 → 지도 클릭으로 직접 찍기 (마커는 끌어서 수정)
4. 각 홀의 파를 확인하고 **JSON 파일로 저장**
5. 그 파일을 `app/courses/` 에 넣고 `app/courses/index.json` 목록에 파일 이름 추가

## 데이터와 저작권 메모 (법률 자문 아님)

- **사실 정보**(홀 번호, 파, 그린의 위치 좌표)는 그 자체로는 저작권 대상이 아닙니다.
- 하지만 **다른 회사(거리측정기·골프앱 회사)의 데이터를 통째로 가져오면** 안 됩니다. 저작권법의 "데이터베이스 제작자 보호"와 부정경쟁방지법(남의 성과물 무단 사용)에 걸릴 수 있고, 그런 회사들은 일부러 넣어둔 표시용 가짜 점 같은 방법으로 베낀 것을 찾아내기도 합니다.
- **OpenStreetMap**: 무료로 써도 되지만 "© OpenStreetMap contributors" 표시가 필요하고(ODbL), 이걸로 만든 데이터베이스를 공개 배포하면 같은 조건으로 공개해야 할 수 있습니다.
- **위성사진 위에서 직접 찍기**: 구글·네이버·카카오 지도는 약관상 사진을 보고 데이터를 뽑아내는 것을 금지하는 편입니다. 국토부 **브이월드**는 공공 자료라 비교적 자유롭지만 이용 약관을 꼭 확인하세요.
- **가장 깨끗한 방법**: 직접 라운드하면서 그린에서 위치를 찍는 것(내가 측정한 데이터).
- **골프장 홈페이지 정보**(회원가입 후 보는 것 포함): 파·거리 같은 사실은 참고해 직접 입력해도 대체로 문제없습니다. 단 **코스 그림·사진·설명 글은 저작물**이라 복사하면 안 되고, 자동 수집(크롤링)은 사이트 약관 위반이 될 수 있습니다.
- 유료 서비스로 낼 계획이면 출시 전에 변호사 확인을 권합니다.

## 음성 안내 · 추천 클럽 · 워치 (계획)

- **지금 되는 것**: 처음 화면 → "내 클럽 거리"에 클럽별 거리를 넣으면, 거리 화면에 추천 클럽이 나오고 [🔊 음성으로 듣기]로 휴대폰 기본 한국어 음성이 읽어줍니다.
- **내 목소리 음성팩 (다음 단계)**: "남은 거리 / 일~구 / 십 / 백 / 미터 / 클럽 이름" 같은 짧은 녹음 조각을 이어 붙여 읽는 방식. 본인 또는 허락받은 목소리만 사용.
- **워치 앱 (다음 단계)**: 휴대폰을 카트에 두면 휴대폰 GPS는 카트 위치를 재므로, 거리는 워치 GPS로 직접 재야 함.
  1. 갤럭시워치(Wear OS) 앱: 버튼 → 워치 GPS로 남은 거리 + 추천 클럽을 워치 스피커로 안내. 골프장·클럽 정보는 휴대폰에서 미리 받아둠.
  2. 애플워치 앱: 아이폰 앱과 함께 제작 (맥 컴퓨터 필요).

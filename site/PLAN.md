## 0. 꼭 지킬 원칙 (모든 페이지 공통)

1. **사이트의 주인은 제이에스 엔지니어링입니다.** 로고, 색, 문구의 주어는 모두 제이에스 엔지니어링입니다. ESPEC 본사 사이트처럼 보이지 않게 합니다.
   - 첫 화면, 상단 메뉴, 하단 정보 어디서든 "ESPEC 한국 단독 총대리점"이라는 표시가 보여야 합니다.
   - ESPEC 로고는 "단독 총대리점" 배지 영역과 파트너 네트워크 영역에만 작게 씁니다 (사용 허가 확인 필요, 9장 참고). 허가 전에는 글자로만 "ESPEC"을 표기합니다.
   - 참고 시안의 히어로 사진처럼 ESPEC 로고가 크게 보이는 장비 사진은 첫 화면에 쓰지 않습니다. 첫 화면은 제이에스 엔지니어링 사옥·현장 사진을 우선합니다.
2. **문구는 새로 씁니다.** ESPEC 영문 문구를 번역해 옮기지 않고, 한국 시험 담당자의 언어("어떤 시험에 쓰나", "어떤 규격에 맞나")로 다시 씁니다.
3. **없는 사실은 쓰지 않습니다.** 연혁, 납품 실적, 고객사, 인증, 응답 시간 등 자료에 없는 것은 `[확인 필요]` 자리표시로 둡니다. 제작 단계에서도 임의로 채우지 않습니다.
   - **참고 시안의 숫자(20+ Years, 500+ Installed Base, 100+ Global Customers, 24/7 Technical Support)와 해외 거점(베트남 지사, 미국·유럽 파트너 등)은 예시일 뿐입니다. 그대로 쓰지 않습니다.** 근거 있는 숫자(1981년 설립 = 45년, 1981년 ESPEC 총판 계약, 연 3~4회 ESPEC 기술 세미나)만 씁니다.
4. **사양 수치는 출처를 남깁니다.** 제품 사양표 아래에 "ESPEC 공개 자료(수집일 2026-10-29) 기준. 최신 사양과 국내 공급 사양은 제이에스 엔지니어링에 문의해 주세요." 문구와 원문 링크를 둡니다.
5. **카탈로그 PDF는 우리 서버에 올리지 않습니다.** ESPEC 저작물이므로 "ESPEC 공식 카탈로그 링크(새 창)" + "제이에스 엔지니어링에 자료 요청" 두 가지 방식으로만 제공합니다. (참고 시안의 "카탈로그 다운로드" 버튼은 "카탈로그 보기"로 바꿔 씁니다.)

## 1. 목적과 방문자

### 사이트의 목적
1. 국내 고객이 "ESPEC 장비는 제이에스 엔지니어링에 문의하면 된다"는 것을 바로 알게 한다. (총대리점 신뢰)
2. 시험 담당자가 **산업 분야, 시험 목적과 규격**으로 알맞은 장비를 빠르게 좁히게 한다.
3. 좁힌 장비로 **견적 문의·자료 요청**을 남기게 한다. (사이트의 최종 성과)
4. 기존 고객이 **A/S·위탁 시험·세미나** 같은 서비스를 쉽게 요청하게 한다. (2차 수정 추가)

### 주요 방문자와 방문 목적
| 방문자 | 주로 하러 오는 일 | 사이트가 해 줄 일 |
|---|---|---|
| 반도체·전자부품 제조사 품질/신뢰성 담당자 | JEDEC·IPC·AEC-Q100 등 규격 시험용 장비 찾기, HAST·온도 사이클 장비 비교 | 솔루션(반도체·전기전자) → 사양 비교표 → 견적 |
| 배터리·전기차 업체 개발/안전 시험 담당자 | 충방전 시험용 챔버, 안전 시험기(못 관통·압괴·단락) 확인 | 솔루션(배터리) → 배터리 장비 상세 + 안전 옵션 상담 |
| 자동차 부품(전장) 업체 시험 담당자 | 급속 온도변화, 열충격, LV 124 같은 규격 대응, 진동 시험 확인 | 솔루션(자동차·모빌리티), 규격별 장비 찾기, 카탈로그 |
| 항공우주·방산 시험 담당자 | 고도(저기압), 열충격, 진동 시험 장비 확인 | 솔루션(항공우주·방산) + 상담 |
| 대학·국공립 연구소 연구원 | 소형 항온항습기, 특수 시험기 사양 확인, 예산 견적 | 솔루션(소재·기타), 소형 장비 모아 보기, 견적서 요청 |
| 데이터센터·AI 서버 관련 기업 | 고발열 서버 시험용 워크인 챔버 확인 | 대표 제품 강조 카드 + 상담 |
| 공인 시험기관 (KTL, KTR, KCL 등 거래처 유형) | 장비 증설, 유지보수 | 제품 + 서비스 |
| 기존 고객(이미 ESPEC 장비 보유) | 유지보수·A/S 문의, 단종 모델 후속 기종 확인 | 서비스 → A/S 요청 |
| 시험 장비가 없는 중소기업 | 장비를 사지 않고 시험만 맡기기 | 서비스 → 위탁 시험소 (시험 항목 `[확인 필요]`) |
| 구매 담당자 | 공급사 신뢰도(총대리점 여부, 회사 이력) 확인 | 회사소개(1981년 설립, 1981년 총판 계약, 연혁) |

### 참고 시안에서 가져온 것 / 가져오지 않은 것
- 가져온 것: 6개 메뉴와 오른쪽 견적문의 버튼, 큰 사진 첫 화면 + 영문 큰 문구 + 한글 부제, 첫 화면 아래 4개 바로가기, 산업 사진 카드 6개, 왼쪽 카테고리 + 상단 탭 + 흰 배경 제품 카드, 제품 상세의 사진 줄·아이콘 수치·체크 목록·탭 줄, 회사소개의 큰 사진 + 숫자 줄, 지도 + 거점 카드, 흰 바탕 + 짙은 네이비 버튼 색 조합
- 가져오지 않은 것: 예시 숫자(20+, 500+, 100+, 24/7), 근거 없는 해외 거점(베트남·미국·유럽), 언어 선택(KR), 3D 보기, 인기순 정렬, ESPEC 로고가 크게 보이는 첫 화면 장비 사진, "카탈로그 다운로드"(→ "카탈로그 보기")
- 색·글꼴은 디자인 담당이 정하되, 조사 자료의 "흰 배경 + 짙은 네이비 + 강조색 1개", Pretendard 권장을 따르는 것을 권합니다. 단, **ESPEC 브랜드 색을 주색으로 쓰지 않아** 본사 사이트와 구별되게 합니다.
- 피할 것: 회전 캐러셀 첫 화면, 채팅 팝업, 과한 패럴럭스, 전면 다크 모드, 자동재생 소리.

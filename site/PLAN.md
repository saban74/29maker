## 0. 꼭 지킬 원칙 (모든 페이지 공통)

1. **사이트의 주인은 쏘울 에이전트입니다.** 로고, 색, 문구의 주어는 모두 쏘울 에이전트입니다. ESPEC 본사 사이트처럼 보이지 않게 합니다.
   - 첫 화면, 상단 메뉴, 하단 정보 어디서든 "ESPEC 한국 공식 총대리점"이라는 표시가 보여야 합니다.
   - ESPEC 로고는 "공식 총대리점" 배지 영역에만 작게 씁니다 (사용 허가 확인 필요, 9장 참고). 허가 전에는 글자로만 "ESPEC"을 표기합니다.
2. **문구는 새로 씁니다.** ESPEC 영문 문구를 번역해 옮기지 않고, 한국 시험 담당자의 언어("어떤 시험에 쓰나", "어떤 규격에 맞나")로 다시 씁니다.
3. **없는 사실은 쓰지 않습니다.** 연혁, 납품 실적, 고객사, 인증, 응답 시간 등 자료에 없는 것은 `[확인 필요]` 자리표시로 둡니다. 제작 단계에서도 임의로 채우지 않습니다.
4. **사양 수치는 출처를 남깁니다.** 제품 사양표 아래에 "ESPEC 공개 자료(수집일 2026-10-29) 기준. 최신 사양과 국내 공급 사양은 쏘울 에이전트에 문의해 주세요." 문구와 원문 링크를 둡니다.
5. **카탈로그 PDF는 우리 서버에 올리지 않습니다.** ESPEC 저작물이므로 "ESPEC 공식 카탈로그 링크(새 창)" + "쏘울 에이전트에 자료 요청" 두 가지 방식으로만 제공합니다.

### 공통 머리말(헤더)
- 왼쪽: 쏘울 에이전트 로고 + 그 옆(또는 아래)에 작은 배지 "ESPEC 한국 공식 총대리점"
- 가운데: 상단 메뉴 (3장)

## 1. 목적과 방문자

### 사이트의 목적
1. 국내 고객이 "ESPEC 장비는 쏘울 에이전트에 문의하면 된다"는 것을 바로 알게 한다. (총대리점 신뢰)
2. 시험 담당자가 **시험 목적과 규격**으로 알맞은 장비를 빠르게 좁히게 한다.
3. 좁힌 장비로 **견적 문의·자료 요청**을 남기게 한다. (사이트의 최종 성과)

### 주요 방문자와 방문 목적
| 방문자 | 주로 하러 오는 일 | 사이트가 해 줄 일 |
|---|---|---|
| 반도체·전자부품 제조사 품질/신뢰성 담당자 | JEDEC·IPC·AEC-Q100 등 규격 시험용 장비 찾기, HAST·온도 사이클 장비 비교 | 용도별 찾기 → 사양 비교표 → 견적 |
| 배터리·전기차 업체 개발/안전 시험 담당자 | 충방전 시험용 챔버, 안전 시험기(못 관통·압괴·단락) 확인 | 배터리 장비 상세 + 안전 옵션 상담 |
| 자동차 부품(전장) 업체 시험 담당자 | 급속 온도변화, 열충격, LV 124 같은 규격 대응 확인 | 규격 기준 검색, 카탈로그 |
| 대학·국공립 연구소 연구원 | 소형 항온항습기, 특수 시험기 사양 확인, 예산 견적 | 소형 장비 모아 보기, 견적서 요청 |
| 데이터센터·AI 서버 관련 기업 | 고발열 서버 시험용 워크인 챔버 확인 | 신제품 소개 + 상담 |
| 기존 고객(이미 ESPEC 장비 보유) | 유지보수·A/S 문의, 단종 모델 후속 기종 확인 | 문의 유형 "A/S·유지보수" |
| 구매 담당자 | 공급사 신뢰도(총대리점 여부, 회사 이력) 확인 | 회사 소개, 총대리점 증명 |

## 3. 메뉴 구성

### 상단 메뉴 (왼쪽부터, 5개 + 버튼 1개)
| 순서 | 메뉴 이름 | 연결 | 펼침 메뉴 |
|---|---|---|---|
| 1 | 제품 | products | 8개 제품군 + "그 밖의 라인업" |
| 2 | 용도별 찾기 | applications | 시험 목적별 / 산업 분야별 |
| 3 | 자료실 | resources | 없음 |
| 4 | 뉴스 | news | 없음 |
| 5 | 회사 소개 | about | 인사말 / 45년 연혁 / 공식 총대리점 / 오시는 길 |
| 버튼 | **견적 문의** | contact | 없음 (강조색 버튼) |

- 이유: 방문자 대부분은 장비를 찾으러 오므로 "제품"과 "용도별 찾기"를 앞에 둡니다. 트렌드 자료의 "메뉴 7개 이상 피하기"에 맞춰 5개로 줄였습니다.
- "견적·문의"는 메뉴가 아니라 버튼으로 두어 항상 눈에 띄게 합니다.
- 모바일 메뉴: 같은 순서, 맨 아래에 전화 걸기 버튼 `[확인 필요: 번호]`.

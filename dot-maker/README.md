# 🎨 도트 캐릭터 메이커 (혼자 쓰는 버전)

서버도, 설치도, 인터넷도 필요 없습니다. **`index.html` 을 더블클릭**하면 브라우저에서 바로 열립니다.
(크롬, 엣지, 웨일, 사파리 모두 됩니다)

## 할 수 있는 것
| 기능 | 방법 |
|---|---|
| 캐릭터 꾸미기 | 오른쪽 탭(얼굴·머리·하의·신발·상의·모자·방패·무기)에서 고르기 |
| 색 바꾸기 | 아래 "색깔"에서 부분을 고르고 색 누르기 (그림자·외곽선은 자동) |
| 🎲 랜덤 | 누를 때마다 새 캐릭터 |
| 움직임 보기 | 가만히 / 걷기 / 공격 / 점프 |
| PNG 그림 | 투명 배경, 32px ~ 512px |
| 스프라이트 시트 | 움직임 4줄을 한 장에 (게임 만들 때 사용) |
| 📦 보관함 | 이름 넣고 [저장] → 그림을 누르면 다시 불러옴, ✕ 로 지우기 |
| 백업 | [보관함 백업 파일 받기] → 다른 컴퓨터에서 [백업 파일 열기] |
| 캐릭터 코드 | 캐릭터 하나를 글자로 복사해서 메신저로 보내기 |

## 꼭 알아 둘 것
- 만들던 캐릭터와 보관함은 **이 컴퓨터의 이 브라우저**에 저장됩니다.
  브라우저 기록을 지우거나 다른 브라우저로 열면 안 보이니, 가끔 **백업 파일**을 받아 두세요.
- 폴더 안 파일 4개(`index.html`, `maker.js`, `dot-engine.js`, `maker-parts.js`)는 항상 **같은 폴더**에 두세요.

## 부품을 직접 추가하고 싶다면
`maker-parts.js` 를 메모장으로 열어 보세요. 글자로 점을 찍어 그린 그림이 들어 있습니다.
예) `h` = 머리색 점, `.` = 빈칸. 비슷한 부품을 복사해서 조금 고치는 것부터 시작하면 쉽습니다.
고친 뒤 저장하고 브라우저를 새로고침하면 바로 나타납니다.

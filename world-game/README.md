# 함께 만드는 세상 🌱

아무것도 없는 **빈 땅**에 접속한 사람들이 함께 길을 깔고, 집을 짓고, 나무를 심으며 세상을 만들어 가는 웹 게임입니다.
게임 속 **아이템과 세상의 규칙도 개발자들이 함께 만들어 갑니다.**

> 이 폴더는 회사 홈페이지와 상관없는 별도 프로젝트입니다.

---

## 1. 실행하기 (3단계)

컴퓨터에 [Node.js](https://nodejs.org) (버전 18 이상)가 있어야 합니다.

```bash
cd world-game
npm install      # 처음 한 번만
npm start        # 서버 켜기
```

- 게임: http://localhost:3000/
- 아이템 편집기: http://localhost:3000/editor.html

같은 와이파이의 다른 사람은 `http://내컴퓨터IP:3000/` 으로 들어올 수 있습니다.
서버를 끄려면 터미널에서 `Ctrl + C` (세상은 자동 저장됩니다).

## 2. 게임 방법

| 하고 싶은 것 | 방법 |
|---|---|
| 걷기 | `W A S D` 또는 방향키 |
| 놓기 | 왼쪽 클릭 (누른 채 끌면 여러 칸) |
| 지우기 | 오른쪽 클릭 |
| 아이템 고르기 | 아래 칸 클릭 또는 숫자키 `1`~`9` |
| 채팅 | `Enter` |

- 내 주변 6칸 안에서만 만들 수 있습니다.
- "막힘" 아이템(돌벽, 집, 물 등)은 지나갈 수 없습니다.

## 3. 폴더 구조 — 무엇이 어디에 있나요?

```
world-game/
├── server.js        ← 서버 (세상을 기억하고, 모두에게 변화를 알려 줌)
├── public/
│   ├── index.html   ← 게임 화면
│   ├── game.js      ← 화면 그리기, 키보드/마우스 처리
│   ├── style.css    ← 화면 꾸미기
│   └── editor.html  ← 🛠 아이템 편집기 (개발 도구)
├── items/           ← 아이템 파일들 (파일 1개 = 아이템 1개)
└── data/world.json  ← 저장된 세상 (자동 생성, 저장소에 올리지 않음)
```

## 4. 공동 개발자: 아이템 추가하는 법

### 방법 A — 편집기로 (코딩 몰라도 됨)
1. http://localhost:3000/editor.html 열기
2. 아이디, 이름, 색깔, 이모지 등을 넣고 **저장하기**
3. 게임 속 모든 사람에게 **바로** 나타납니다. (`items/` 폴더에 파일도 생깁니다)

### 방법 B — 파일로 직접
`items/` 폴더에 새 파일을 만듭니다. 예) `items/brick.json`

```json
{
  "id": "brick",
  "name": "벽돌",
  "color": "#b24a3b",
  "emoji": "🧱",
  "layer": "object",
  "solid": true,
  "author": "내 이름"
}
```

| 칸 | 뜻 |
|---|---|
| `id` | 영어 소문자·숫자·`-`·`_` (파일 이름과 같게) |
| `name` | 게임에 보이는 이름 (20자 이하) |
| `color` | 색깔 `#RRGGBB` |
| `emoji` | (선택) 칸에 그려질 그림 |
| `layer` | `ground` = 바닥 자체 / `object` = 바닥 위에 놓는 물건 |
| `solid` | `true` = 못 지나감 / `false` = 지나갈 수 있음 |
| `author` | 만든 사람 |

파일을 저장하면 서버를 끄지 않아도 자동으로 반영됩니다.

## 5. 함께 개발하는 흐름 (GitHub)

1. 이 저장소를 받습니다 (`git clone`).
2. 내 작업용 가지(branch)를 만듭니다: `git checkout -b 내이름/새아이템`
3. 아이템을 추가하거나 코드를 고칩니다.
4. 올립니다: `git add` → `git commit` → `git push`
5. GitHub에서 **Pull Request** 를 만들어 다른 개발자에게 확인받고 합칩니다.

> 💡 편집기로 만든 아이템도 `items/` 폴더의 파일이므로, 위와 같이 커밋하면 다른 개발자와 공유됩니다.

## 6. 공개 서버에서 운영할 때

- 아무나 아이템을 바꾸지 못하게 **개발자 키**를 정하세요:
  ```bash
  DEV_KEY=비밀번호 npm start
  ```
  편집기에서 저장할 때 이 키를 입력해야 합니다. 키는 공동 개발자끼리만 나눕니다.
- 포트 바꾸기: `PORT=8000 npm start`

## 7. 🎨 도트 캐릭터 메이커

http://localhost:3000/maker.html (게임 화면 위쪽 **캐릭터 만들기**)

- 부품 고르기: 얼굴, 머리, 상의, 하의, 신발, 모자, 방패, 무기
- 색 바꾸기: 9가지 부분마다 색을 따로 정할 수 있음 (그림자는 자동)
- 움직임 보기: 가만히 / 걷기 / 공격 / 점프
- 내려받기: PNG 그림, 스프라이트 시트 (한 줄에 움직임 하나, 투명 배경)
- 캐릭터 코드: 복사해서 친구에게 보내면 똑같은 캐릭터를 불러올 수 있음

**새 부품 추가하기:** `public/maker-parts.js` 파일에 글자 그림으로 그립니다.
예) 머리 모양 하나 = 아래처럼 `h`(머리색) 글자로 점을 찍은 것. 외곽선은 자동입니다.

```js
{ name: "짧은 머리", at: [10, 4], map: [
  "...hhhhhh...",
  "..hhhhhhhh..",
  ".hhhhhhhhhh.",
] },
```

## 8. 🌍 월드 스튜디오 · 🏞 쇼케이스

http://localhost:3000/studio.html · http://localhost:3000/showcase.html

1. 메이커에서 캐릭터를 만들고 **[🌍 월드 스튜디오로 보내기]** 에 이름·직업·성격·말투를 넣어 **캐스트로 저장**
2. 스튜디오 오른쪽 **캐스트 고르기** 에서 **[월드에 넣기]** (한 월드에 12명까지, 예시 캐릭터 4명 포함)
3. 캐릭터들은 스스로 돌아다니고, 가까이 있으면 각자 말투로 말을 겁니다.
4. 캐릭터를 누르고 명령: **대화 / 이동**(지도에서 갈 곳 누르기) **/ 휴식 / 되돌리기**
5. **🖌 땅 그리기** 로 풀밭·길·물·나무·꽃밭·바위를 칠할 수 있음
6. **스냅샷 내보내기 / 불러오기**: 월드를 파일로 저장하고 다시 열기
7. **🚀 게시하기**: 공개 링크가 생기고 쇼케이스에 올라감 (`data/worlds/` 에 저장)

| 파일 | 하는 일 |
|---|---|
| `public/dot-engine.js` | 캐릭터 그리기 엔진 + 말투 목록 (메이커·스튜디오 공용) |
| `public/world-tiles.js` | 땅 타일 그림과 기본 지도 |
| `public/studio.js` | 스튜디오: 돌아다니기, 길찾기, 대화, 명령, 게시 |
| `public/showcase.html` | 게시된 월드 목록 (검색·정렬) |

새 말투를 추가하려면 `dot-engine.js` 의 `SPEECH_STYLES` 에 한 덩어리를 추가하면 됩니다.

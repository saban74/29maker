보병 전선 - 실행 방법

■ 내 컴퓨터에서 실행 (별도 창으로 바로 뜸)
  Windows : PLAY-Windows.bat 더블클릭
            → 검은 창(게임 서버)이 뜨고, 게임이 주소창 없는 전용 창으로 열립니다.
            → 게임을 끝낼 때는 검은 창도 닫아 주세요.
            → 도감은 게임 창 주소 뒤를 dogam.html 로 바꾸거나, 게임 안의 도감 버튼으로 볼 수 있습니다.
            → "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
  Mac     : PLAY-Mac.command 더블클릭 (처음엔 우클릭 → 열기)
  * index.html 이나 game.html 을 바로 더블클릭하면 그림·소리가 막혀서 제대로 안 나옵니다.

■ 내 사이트에 올리기 (예: 029.kr)
  이 폴더 안의 파일 전체를 웹 서버의 한 폴더에 그대로 올립니다.
  접속하면 시작 화면이 나옵니다.
   - [새 창으로 게임 시작] : 게임이 별도 창으로 열립니다. (팝업 차단이 뜨면 허용)
   - [앱으로 설치]         : 크롬·엣지에서 바탕화면 아이콘이 생기고,
                             다음부터 아이콘을 누르면 주소창 없는 전용 창으로 실행됩니다.
                             (https 주소에서만 나타납니다)
   - [도감 보기]           : 캐릭터 도감이 별도 창으로 열립니다.
                             도감 안의 ‘움직임과 효과음으로 보기’를 누르면 3D 도감이 열립니다.
   - [이 창에서 시작]      : 지금 창에서 바로 시작합니다.

■ 인터넷
  게임은 인터넷 없이도 돌아갑니다(3D 엔진 파일을 lib 폴더에 함께 넣었습니다).
  글꼴만 인터넷에서 받아오며, 없으면 기본 글꼴로 보입니다.

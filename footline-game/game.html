보병 전선

병사가 저절로 나와 싸우는 4인 3D 전장. 인간 성과 오크 요새가 맞서는 전장에서 다섯 영웅 가운데 하나를 골라 마지막까지 버티세요.

전투 준비

영웅 고르기

방식

컴퓨터 난이도

조작: 땅을 클릭하면 영웅 이동, 적을 클릭하면 공격. 카메라는 늘 내 영웅을 따라가요. 끌거나 WASD·방향키·미니맵으로 잠깐 다른 곳을 볼 수 있고, 손을 떼면 1.5초 뒤 영웅에게 돌아와요(스페이스: 바로 돌아오기). 휠은 확대/축소, Q 스킬. 병사는 10초마다 저절로 나오고 "군대 목표"로 정한 곳으로 진격합니다.

조사로 확인한 Footman 계열 맵의 공통 규칙
  • "Footmen Wars(풋맨워)"는 맵 하나가 아니라 장르 이름입니다. 공통점은 각 기지에서 병사가 주기적으로 계속 나오고, 기지가 부서지면 패배한다는 것.
  • Footmen Frenzy 계열: 4모서리에서 시작(팀당 최대 3명), 본진(0티어)에서 보병이 나오고 본진에서 군대 업그레이드와 영웅 부활.
  • 병사 자동 생성 주기 10초 (Dota 2 위키의 Footmen Frenzy 설명).
  • 티어는 시간이 지나야 열림 (v7.0: 1티어는 5분 뒤 구매 가능). 티어 비용 예: 1050 / 1400 / 2000 / 4000 (버전마다 다름).
  • 영웅 자동 부활 시간 23 + 레벨×2 초 (v7.0 패치 노트).
  • 유닛·영웅 처치 시 금화, 근처 영웅은 경험치 획득.
  • 맵 중앙에 특별 지역(Archvault: 마나 회복이 빠름)이 있어 차지 싸움이 벌어짐.
보병 전선에 적용한 방식
  • 4모서리 기지, 4인 개인전 또는 2:2 팀전. 기지가 부서지면 탈락.
  • 10초마다 병사 자동 생성 → "군대 목표"로 정한 기지로 진격.
  • 티어 0~4: 1분 30초 / 4분 / 7분 / 10분부터 구매 가능. 짧은 판에 맞게 비용과 시간을 줄였습니다.
  • 영웅 부활 23 + 레벨×2 초, 최대 10레벨.
  • 중앙 "성소": 영웅의 체력 회복 증가, 스킬 대기시간 2배 빠름. 지키는 중립 몬스터가 있습니다.
  • 맵 가장자리 4곳 중립 몬스터 캠프 (90초 뒤 다시 생김).
  • 방어력 공식은 워크래프트3 방식(방어 1당 피해 약 6% 감소, 점점 줄어듦).
  • 맵 배치(나무·캠프 위치)는 원작을 복제하지 않고 같은 구조로 새로 그렸습니다.
캐릭터 바꾸는 법
  • 코드 맨 위 DATA에서 영웅 이름·능력치·스킬, 병사 종류, 티어 구성을 바꿉니다.
  • 캐릭터 모양은 MODELS에서 상자·원기둥·구 같은 기본 도형을 조립해 만듭니다. 영웅 3명(벨릭·세아·오렌)과 병사·몬스터는 이 게임을 위해 새로 디자인했습니다.

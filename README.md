# JS Engineering 홈페이지 (시안)

(주)제이에스엔지니어링 새 홈페이지 시안입니다. `index.html`을 브라우저로 열면 바로 볼 수 있습니다.
목적: **제품 홍보 · 영업 문의 · 서비스(A/S) 문의**

## 페이지 구성
1. 첫 화면 – 장비 7대가 나란히 선 쇼룸. 클릭하면 앞으로 나오며 조명·정보창·시험 온도 연출
2. 제품 – 시험 조건(온습도/열충격/HAST/2차전지/워크인)으로 골라보기, "이 제품 문의" 누르면 문의 폼에 제품명 자동 입력
3. 서비스 – 상담 → 설치 → 교정 → A/S 흐름, A/S 바로 접수
4. 회사 – 1981년 설립, ESPEC · SHINKEN 파트너
5. 문의 – 견적/A·S/기술상담 선택형 폼

## 꼭 확인·교체할 내용
- 전화번호, 이메일, 상세 주소, 사업자등록번호 (지금은 임시값)
- 제품 사양: 외형 치수는 ESPEC 외형도 기준. 아래 온도 범위는 도면에 없어서 확인 필요
  - PL-2J -40~+100°C, SH-642 -40~+150°C (일반 카탈로그 값)
  - ARGF-0400, TCC-151W, TSA-73ES-W 온도 범위 미표기
  - EBU 워크인 -30~+80°C 는 도면 기재값
- 첫 화면 장비 6대는 실제 치수 비율(같은 축척)로 그린 정면도입니다. HAST·2차전지는 도면이 없어 제품 목록에만 아이콘으로 표시
- "ESPEC Authorized Partner" 표기 가능 여부 (ESPEC과 확인)
- 문의 폼은 아직 실제 전송이 안 됨 (메일 연결 필요)
- 장비 그림은 직접 그린 일러스트입니다. 실제 사진으로 바꾸려면:
  1. 정면에서 같은 조명으로 찍고 **배경을 지운 PNG**로 준비 (예: `images/platinous.png`)
  2. `index.html`의 해당 `<button class="unit">` 안 `<svg>…</svg>`를 `<img src="images/platinous.png" alt="">`로 교체
- 장비 이름·사양·설명은 `script.js` 위쪽 `machines` 목록에서 수정

## 제품 상세 페이지
- `platinous.html` – 항온항습챔버 PLATINOUS J (첫 화면 정보창·제품 카드의 "자세히 보기"에서 연결)
- 장비 사진: `images/products/platinous-j.webp` – ESPEC 공식 배너에서 장비만 잘라 배경 제거·선명화 (ESPEC 사용 허락 및 고해상도 원본 요청 권장)
- 확인 필요: 온도 -40~+100°C, 습도 20~98% RH (카탈로그 확인), 용량 225L은 도면 내부치수(500×750×600)로 계산
- 디자인은 `product.css`, 동작은 `product.js`. 다른 제품 페이지도 이 파일을 복사해 만들면 됩니다

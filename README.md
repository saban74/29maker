# JS Engineering 홈페이지 (시안)

(주)제이에스엔지니어링 새 홈페이지 시안입니다. `index.html`을 브라우저로 열면 바로 볼 수 있습니다.
목적: **제품 홍보 · 영업 문의 · 서비스(A/S) 문의**

## 페이지 구성
1. 첫 화면 – 챔버 온도가 -70°C ~ +180°C로 변하는 연출
2. 제품 – 시험 조건(온습도/열충격/HAST/2차전지/워크인)으로 골라보기, "이 제품 문의" 누르면 문의 폼에 제품명 자동 입력
3. 서비스 – 상담 → 설치 → 교정 → A/S 흐름, A/S 바로 접수
4. 회사 – 1981년 설립, ESPEC · SHINKEN 파트너
5. 문의 – 견적/A·S/기술상담 선택형 폼

## 꼭 확인·교체할 내용
- 전화번호, 이메일, 상세 주소, 사업자등록번호 (지금은 임시값)
- 제품 시리즈명·사양 (검색으로 모은 대표값이라 실제 취급 모델과 맞춰야 함)
- "ESPEC Authorized Partner" 표기 가능 여부 (ESPEC과 확인)
- 문의 폼은 아직 실제 전송이 안 됨 (메일 연결 필요)
- 제품 그림은 아이콘입니다. 실제 제품 사진으로 교체 권장

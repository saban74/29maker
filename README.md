## AI 에이전트

`.claude/agents/` 폴더에 Claude Code용 AI 에이전트(서브에이전트)가 들어 있습니다.
조사, 기획, 글쓰기, 개발 등 다양한 주제에 두루 쓸 수 있는 팀입니다.

| 이름 | 하는 일 | 파일 수정 |
|------|---------|-----------|
| `researcher` | 어떤 주제든 웹에서 조사해 출처와 함께 정리 | 안 함 |
| `planner` | 막연한 아이디어를 단계별 계획으로 정리 | 안 함 |
| `writer` | 글쓰기, 요약, 번역, 다듬기 | 요청할 때만 |
| `code-explainer` | 코드를 입문자 눈높이로 쉽게 설명 | 안 함 |
| `code-reviewer` | 코드의 버그, 보안 문제, 개선점 점검 | 안 함 |

사용 예 (Claude Code에서 입력):

- `researcher 에이전트로 요즘 인기 있는 무료 사진 편집 프로그램 비교해줘`
- `planner 에이전트로 나만의 블로그 만드는 계획 세워줘`
- `writer 에이전트로 동호회 모임 안내 글 써줘`
- `code-explainer 에이전트로 README.md 설명해줘`
- `code-reviewer 에이전트로 방금 만든 코드 검토해줘`

에이전트 이름을 말하지 않아도, Claude가 `CLAUDE.md`의 안내에 따라 알맞은 에이전트를 골라 맡깁니다.

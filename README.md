# 29maker 홈페이지

한 페이지짜리 소개용 홈페이지입니다. 별도 설치 없이 `index.html`을 브라우저로 열면 바로 볼 수 있습니다.

## 파일 구성
| 파일 | 하는 일 |
|---|---|
| `index.html` | 글자·내용 (메뉴, 소개, 서비스, 작업물, 문의) |
| `style.css` | 색상·디자인 (맨 위 `:root`의 `--primary` 값을 바꾸면 대표 색이 바뀝니다) |
| `script.js` | 모바일 메뉴, 문의 폼 동작 |

## 내용 바꾸기
- 회사 소개·연락처: `index.html`에서 해당 문장을 찾아 바꾸면 됩니다.
- 작업물 사진: 지금은 색 그라데이션 상자입니다. 나중에 이미지로 바꿀 수 있습니다.
- 문의 폼: 아직 실제로 메일이 가지 않습니다(안내 문구만 표시).

## 인터넷에 공개하기 (GitHub Pages)
저장소 **Settings → Pages**에서 브랜치를 선택하고 저장하면 `https://saban74.github.io/29maker/` 주소로 공개됩니다.

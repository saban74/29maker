# 골목 삼국지 — 겨울방학 천하통일 (가칭) · 기획 초안 v0.1

> "삼국지"처럼 영토를 넓히고, 장수를 모으고, 내정과 외교와 전쟁을 하는 **턴제 전략 시뮬레이션**.
> 무대는 남양주 동네들이고, 장수는 동네 아이들입니다. 겨울방학이 끝나 눈이 녹기 전에 남양주를 통일해야 합니다.

- 장르: 턴제 전략 시뮬레이션 (영토 · 내정 · 외교 · 전투)
- 플랫폼: 모바일 가로 화면 우선 (웹 → 원스토어 / 구글 플레이)
- 한 턴: 게임 속 **하루** (실제 1~3분)
- 한 판: **겨울방학 60일** (약 2~4시간), 여러 시나리오
- 특정 게임(코에이 「삼국지」 시리즈 등)의 이름, 인물, 화면, 시스템 구성을 베끼지 않습니다. "영토 확장형 턴제 전략"이라는 장르만 따릅니다.
- 「눈싸움 동네 평정기」의 아이 28명, 동네 7곳, 지도, 전장 그림, 아이템, 음악을 그대로 재사용합니다. 그래서 그림 작업이 적게 듭니다.

## 1. 한눈에 보기

| 삼국지식 요소 | 이 게임에서 | 설명 |
|---|---|---|
| 군주 | **동네 대장** | 7개 동네의 대장(지용, 서호, 재하, 민석, 재준, 건우, 진호) |
| 장수 | **동네 아이들** | 각자 능력치, 특기, 성격이 있음 |
| 성 / 도시 | **놀이터·공원·운동장** | 동네마다 거점 1~3곳 |
| 금 | **딱지** | 장비, 간식, 스카우트에 씀 |
| 군량 | **간식** (붕어빵, 핫초코) | 원정을 나가면 매일 줄어듦 |
| 병력 | **꼬마 부대** (동생들, 반 친구들) | 장수 1명이 이끄는 아이 수 |
| 충성도 | **우정도** | 낮으면 다른 동네로 "전학"(배신) |
| 계절 · 수명 | **겨울방학 60일** | 개학하면 게임 끝. 눈이 녹기 전에 통일해야 함 |
| 천재지변 | **엄마, 시험, 감기, 폭설** | 매일 무작위 사건 |

## 2. 게임의 흐름

```
시나리오 선택 → 시작할 동네(세력) 선택
  ↓
[하루 = 한 턴]
  1. 아침 사건 (날씨, 엄마, 학원, 감기 ...)
  2. 내 차례: 거점마다 명령 1개씩
     - 내정: 놀이터 꾸미기 / 문방구 장사 / 간식 모으기 / 친구 모으기
     - 인사: 장수 이동 / 스카우트 / 상 주기(우정도)
     - 외교: 동맹 / 휴전 / 이간질 / 선물
     - 군사: 원정 / 방어 / 훈련
  3. 다른 동네(AI) 차례
  4. 전투가 생기면 → 눈싸움 전투 (턴제)
  5. 저녁: 수입 정산, 간식 소비, 우정도 변화
  ↓
60일 안에 모든 거점을 차지하면 "남양주 통일" 엔딩
개학날이 되면 그때까지 차지한 땅으로 순위와 엔딩이 갈림
```

## 3. 지도와 거점

- 「눈싸움 동네 평정기」의 **남양주 월드맵**을 그대로 씁니다.
- 7개 동네, 동네마다 거점 1~3곳으로 **모두 14곳**입니다.

| 동네 | 거점 (예시) | 특산 (수입 보너스) |
|---|---|---|
| 다산동 | 아파트 놀이터, 다산 문방구, 학교 앞 | 딱지 + |
| 별내동 | 공원 광장, 별내역 | 친구 모으기 + |
| 호평동 | 상가 골목 | 간식 + |
| 진접읍 | 학교 운동장, 체육관 | 훈련 + |
| 평내동 | 상가 광장 | 딱지 ++ |
| 와부읍(덕소) | 한강변, 덕소역 | 원정 이동 + |
| 화도읍 | 설산 숲, 눈 요새 | 방어 ++ |

- 거점끼리 **길**로 이어져 있고, 이어진 곳으로만 원정을 갈 수 있습니다.
- 확장 시나리오: 구리, 하남, 의정부, 남양주 전체 → "경기 동부 통일"

## 4. 장수 (아이들)

### 4-1. 능력치 5가지 (1~100)
| 능력 | 쓰이는 곳 |
|---|---|
| **통솔** | 이끌 수 있는 꼬마 부대 수, 전투 방어 |
| **무력** | 눈덩이 위력, 일대일 대결 |
| **지력** | 작전(전술) 성공률, 이간질 |
| **정치** | 딱지·간식 수입, 놀이터 꾸미기 |
| **매력** | 친구 모으기, 스카우트, 우정도 유지 |

### 4-2. 기존 아이들 능력치 예시
| 아이 | 동네 | 통솔 | 무력 | 지력 | 정치 | 매력 | 특기 |
|---|---|---|---|---|---|---|---|
| 지용 | 다산 | 75 | 88 | 55 | 40 | 70 | 강속구 (무력 전투 +) |
| 도현 | 다산 | 85 | 60 | 78 | 70 | 82 | 지휘 (부대 사기 +) |
| 재용 | 다산 | 50 | 45 | 70 | 88 | 60 | 눈 공급 (간식 소모 −) |
| 서호 | 별내 | 80 | 85 | 60 | 45 | 68 | 연속투척 |
| 민석 | 진접 | 88 | 80 | 40 | 50 | 75 | 중장갑 (방어 +) |
| 다희 | 와부 | 55 | 60 | 85 | 70 | 72 | 정찰 (적 정보 확인) |
| 진호 | 화도 | 95 | 92 | 65 | 55 | 85 | 거대 눈덩이 (최강 대장) |

(28명 모두 이런 식으로 정합니다. 숫자는 초안입니다.)

### 4-3. 이 게임만의 장수 규칙
- **학원 요일**: 장수마다 학원 가는 요일에는 명령을 받을 수 없습니다. 「동네 평정기」의 시간표를 그대로 씁니다.
- **엄마 감시**: 감시가 심한 아이는 가끔 "숙제하래요"로 하루 쉽니다. 우정도가 높아도 피할 수 없습니다.
- **우정도 (충성도)**: 상을 주거나 같이 이기면 오르고, 오래 쉬게 하거나 지면 내려갑니다. 낮아지면 다른 동네의 스카우트에 넘어가 **"전학"**(배신)합니다.
- **스카우트 (등용)**: 이긴 전투에서 상대 아이를 데려오거나, 딱지와 간식으로 설득합니다. 매력과 우정도로 성공률이 정해집니다.
- **성장**: 전투와 내정을 할수록 능력치가 오릅니다.

## 5. 내정 (거점 관리)

| 명령 | 효과 | 담당 능력 |
|---|---|---|
| 놀이터 꾸미기 | 거점 레벨 ↑ (방어, 수입 증가) | 정치 |
| 문방구 장사 | 딱지 수입 | 정치 |
| 간식 모으기 | 간식(군량) 수입 | 정치 |
| 친구 모으기 | 꼬마 부대(병력) 증가 | 매력 |
| 눈벽 쌓기 | 방어 시설 ↑ (전투 때 엄폐물) | 통솔 |
| 훈련 | 부대 숙련 ↑ | 통솔 |
| 엄마 설득 | 감시 심한 아이를 하루 풀어 줌 | 매력 |

- 날씨가 내정에 영향을 줍니다. 폭설은 눈벽 쌓기 2배, 햇빛은 눈벽이 녹습니다.

## 6. 외교

| 명령 | 효과 |
|---|---|
| **같이 놀자 (동맹)** | 서로 공격 금지, 함께 공격 가능 |
| **휴전** | 정해진 날까지 싸우지 않음 |
| **선물 보내기** | 상대 대장의 호감 ↑ (딱지·간식) |
| **이간질** | 상대 동네 아이의 우정도 ↓ (지력) |
| **상대 엄마에게 이르기** | 상대 장수 하나를 3일 동안 못 나오게 함 (비쌈, 「동네 평정기」 아이템과 연결) |
| **항복 권유** | 약한 동네를 싸우지 않고 흡수 |

## 7. 전투 — 턴제 눈싸움

- 원정을 가거나 공격받으면 **전투 화면**으로 넘어갑니다.
- 전장은 「동네 평정기」의 **그림 전장 7곳**을 칸(격자)으로 나눠 씁니다.
- 양쪽 장수 최대 5명이 각자 **꼬마 부대**를 이끕니다. 화면에는 장수만 보이고, 부대 수는 숫자로 표시합니다.

### 7-1. 내 차례에 장수마다 행동 1개
| 행동 | 내용 |
|---|---|
| 이동 | 2~4칸 (빙판은 미끄러짐) |
| 던지기 | 사거리 안 적에게 공격. 피해 = 무력 × 부대 수 |
| 뭉치기 | 눈덩이(탄약) 충전 |
| 숨기 | 눈벽 뒤에서 받는 피해 감소 |
| 작전 (전술) | 지력으로 특수 행동: 기습, 함정, 눈보라 부르기 |
| 필살기 | 게이지가 차면 장수 고유 기술 |
| 아이템 | 핫초코, 몽패딩, 엄마 소환 등 |

### 7-2. 이 게임다운 규칙
- **손 시림**: 3턴 연속 던지면 1턴 쉼 (장갑 등급에 따라 4~6턴)
- **날씨**: 턴마다 바뀔 수 있음 (함박눈, 눈보라, 햇빛, 빙판)
- **사기**: 장수가 아웃되면 그 부대가 흩어짐. 대장이 아웃되면 전투 패배
- **저녁 6시**: 정해진 턴(예: 15턴)이 지나면 "밥 먹어라~"로 무승부. 수비 쪽이 거점을 지킴
- **자동 전투** 버튼: 빠르게 결과만 보고 싶을 때

## 8. 사건 (매일 아침)

| 사건 | 효과 |
|---|---|
| 함박눈 | 모든 거점 눈벽 +, 친구 모으기 + |
| 감기 유행 | 무작위 장수 2~3명이 며칠 쉼 |
| 시험 기간 (방학 중 학원 시험) | 감시 심한 아이들이 3일 결석 |
| 크리스마스 | 모든 동네 휴전 1일, 선물 효과 2배 |
| 설날 세뱃돈 | 딱지 큰 수입 |
| 전학생 등장 | 무소속 장수가 나타남. 먼저 스카우트한 동네가 데려감 |
| 엄마들 반상회 | "엄마에게 이르기" 사용 불가 3일 |
| 동네 대장 생일 | 그 동네 우정도 전체 + |

## 10. 모바일에 맞춘 설계

- **한 턴 1~3분**: 버스, 지하철에서도 하루씩 진행
- **세로 화면 지원 검토**: 지도와 명령 메뉴는 세로로도 가능
- **자동 내정**: "알아서 해 줘"를 켜면 수입·훈련을 자동 배분
- **자동 저장**: 앱을 꺼도 그 하루부터 다시 시작
- **(확장) 비동기 대전**: 친구와 하루에 한 턴씩 주고받는 대결 (Supabase 사용)

## 11. 수익 아이디어 (출시할 때)

- 무료 + 광고 (턴 사이 짧은 광고, 보상형 광고로 간식·딱지 받기)
- 추가 시나리오 판매
- 장수 꾸미기 (모자, 장갑 색) — 능력치에 영향 없는 것만
- **확률형 아이템(뽑기)은 넣지 않는 것을 추천합니다.** 한국은 확률 공개 의무가 있고, 아이들 배경 게임이라 평판에도 좋지 않습니다.

## 13. 정할 것

1. **게임 이름**: 가칭 「골목 삼국지」. "삼국지"라는 단어를 쓸지, 다른 이름(예: 「동네 천하통일」, 「겨울방학 대전」)으로 할지
2. **「눈싸움 동네 평정기」와의 관계**: 같은 세계관의 다른 게임으로 할지, 동네 평정기 안에 "전략 모드"로 넣을지
3. **전투 방식**: 격자 턴제(초안)로 할지, 기존 실시간 눈싸움을 그대로 쓸지
4. **한 판 길이**: 겨울방학 60일(초안)이 적당한지

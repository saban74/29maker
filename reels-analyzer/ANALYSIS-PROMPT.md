# 릴스 해부 프롬프트 (프롬프트 2)

`fetch-reels.mjs` 로 가져온 `output/<계정>-<날짜>.json` 파일을 Claude Code에 주면서 아래 내용을 붙여 넣습니다.
예) "reels-analyzer/output/nike-2026-11-06.json 파일로 아래 분석을 해줘"

---

상위 10개 릴스를 아래 기준으로 해부해줘.

[레이어 1 · 진입각 — 0~3초]
텍스트 채널: 정보공백 / 이득예고 / 손실경고 / 숫자고정 / 자격증명
  → 해당하는 것 전부, 그리고 겹친 개수를 세라
  → 3초에 던진 걸 본문에서 안 풀면 '미끼'로 따로 표시
화면 채널: 결과선공개 / 통념반박 / 예상이탈 / 전후대비 / 상황공감 / 없음
소리 채널: 첫 발화가 3초 안에 나왔는지
  → 실제로 일한 채널 수를 0~3으로

[레이어 2 · 체류 설계]
전개형: 문제→처방 / 의외→따라하기 / 경험→권유 / 나열
정보 항목 수, 그리고 항목당 몇 초인지
보류 장치: 유형 / 몇 초에 걸었는지 / 전체의 몇 % 지점인지

[레이어 3 · 행동 설계]
저장 / 공유 / 댓글 / 팔로우 / 없음
공유 유도면 대상이 특정됐는지
캡션 첫 줄이 단독으로 후킹하는지
캡션이 본문 반복인지 보완인지
총정리·순위형 구조인지

[레이어 4 · 수요 폭]
동기: 재미 / 해소 / 획득
욕구군: 자원 / 지위 / 역량 / 신체 / 정서
폭: 좁음 / 보통 / 넓음
이 주제를 한 단계 넓히는 경로 1개

[공통 규칙]
모든 항목에 근거 원문을 인용해라. 없으면 '불명'.
영상을 봐야 아는 항목은 [눈으로 확인]으로 따로 모아라.
추측으로 채우지 마라.
다 뜯은 다음에 공통 패턴 3개.
그리고 상위 그룹과 하위 그룹의 수치 차이를 비교해라.
